## Demo 帳號快捷填入

1. 開啟前台或後台登入頁，找到「Demo 帳號快捷填寫」。僅本機開發伺服器顯示，正式 production build 不提供此入口。
2. 選擇本機檔案 `.run/demo-login-ad89d094c36546659ad6f3846eeeb620/demo-login-pack.json`。
3. 按「填入」對應帳號，然後自行按「登入」。前台為 `member-0001@example.invalid`，後台為 `demo-admin@example.invalid`。
4. 後台仍須完成原本的 MFA；工作包不包含繞過驗證的能力。
5. 工作包只載入當頁記憶體，重新整理後需再選檔。可按「卸載工作包」清除已載入的帳號集合；已填入的登入欄位需自行清空或重新整理。

密碼保存在該 JSON，不寫入此文件、前端程式或 Git。請勿公開分享或提交 `.run`。其他電腦需在當地已完成設置的隔離 Demo 以系統 CLI 執行 `./scripts/export-demo-login-pack.ps1`；此操作驗證既有 Demo 密碼後匯出，不重設密碼，也不讀取正式帳號密碼。

結帳頁另有「填入 Demo 聯絡與收件資料（覆寫欄位）」：只填合成姓名、手機及地址；不填／驗證 Email、不勾選條款、不自動送出訂單。展示資料不得實際配送。

## 建議複核順序

1. **會員中心**：登入後按五個精簡按鈕，下方切換訂單、組裝清單、收藏、評價、地址；不是整頁導走。按「回會員資料」返回，編輯時停用切換避免遺失輸入。
2. **商品**：完整頁 24 筆；1／2／3／4 欄對齊。最後一頁不足 24 筆可自然留白。點頁碼與尾頁確認資料變更；詳情應先顯示名稱，再顯示圖片／購買雙欄。
3. **SLA**：切換狀態、優先度、承辦範圍、逾時或排序立即更新；案件編號輸入後約 300ms 查詢，頁碼回第一頁。
4. **會員管理**：由後台「會員管理」進入。SuperAdmin 可查詢、查看遮蔽詳情及啟停用；PrivacyAdmin 只讀。停用／恢復需確認與理由。未驗證信箱、匿名化、已關閉帳號不可用此操作啟用；不可查看密碼或刪除會員。
5. **組裝進度**：後台「營運與物流 → 訂單」開啟訂單詳情。必要時先依原流程「開始處理」。在「組裝工作進度」逐台執行「組裝完成，開始測試」，確認後再執行「測試通過，確認可出貨」。失敗則標記原因，修復後「重新開始組裝」。多台訂單必須全部通過，不能略過測試直接出貨。
6. **批次出貨**：回訂單列表重新勾選，以最新版本建立物流單或標記已出貨。付款、組裝、配送與庫存檢查仍有效；版本衝突需重新讀取，不能重複提交舊資料。Preparing／備貨中不一定已有物流單，是否可開單由伺服器檢查。
7. **註冊／結帳文字**：姓名在註冊表單最上方；錯誤提示繁體中文；公司發票欄位為「公司抬頭」。
