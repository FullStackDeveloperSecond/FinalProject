# DoSelect 懂選｜整站第一版視覺預覽

供組長與組員審查**整體風格、資訊配置、頁面導覽與主要操作流程**用的獨立原型。
**不含任何真實資料、API、資料庫、身分驗證、金流或上傳功能**；所有資料皆為假資料，重新整理即重置。

與 `customer-web`／`admin-web` 兩個正式應用完全獨立，未修改它們任何一行程式。

## 如何開啟

```
node FP.dev/frontend/prototypes/doselect-visual-preview-v1/server.js
```

開啟 <http://localhost:8936/prototypes/doselect-visual-preview-v1/index.html>。
（也可直接以瀏覽器開啟 `index.html`；使用伺服器只是為了讓 `@import` 的 Design Tokens 一定載得到。）

## 設計系統

- 色彩／間距／字級／圓角／陰影／動效**全部來自正式 Design Tokens**：
  `assets/preview.css` 第一行直接 `@import` `../../../shared/src/styles/design-tokens.css`，
  不另建一套色票，也沒有寫死的色碼。
- 狀態徽章沿用共用 `StatusBadge` 的五種語意（`in-progress`／`waiting`／`complete`／`failed`／`stopped`）
  與對應的語意 token，命名為 `.badge--*`。
- 因為本原型是純 HTML／CSS／JS，**無法載入 PrimeVue preset（Vue 專用）**；
  改為直接沿用同一份 token 檔，確保顏色與正式應用同源。

## Donggu 使用

- 專案內目前只有一張正式立繪：`prototypes/donggu-blue-white/assets/images/donggu-official.png`，
  用於品牌標記與首頁 Hero。
- 其他頁面所需的不同動作／表情**尚未匯入專案**，因此以清楚標記的
  「Donggu 立繪預留區」呈現，並標註預定動作（例如「比出 OK 手勢」「歪頭思考」）。
  **未自行生成替代角色，也未改造角色比例或配色。**
- 後台僅在必要處少量使用，避免干擾資訊閱讀。

## 已知限制

- 僅供畫面審查，非正式系統：不會建立訂單、送出案件或寫入任何資料。
- 篩選、分頁、分割面板、步驟切換為真實 DOM 操作；其餘按鈕只顯示示意提示。
- 尚未套用多語系結構（本階段僅繁體中文），文案集中在 `assets/data.js` 與各頁 view。
