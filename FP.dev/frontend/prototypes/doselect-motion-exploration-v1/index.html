三套方案

三套 preset 共用同一組 helper 與同一套安全規則：只動 transform 與 opacity、沒有無限動畫、 沒有 ScrollSmoother、reduced motion 時完全不建立 tween（不是把動畫放慢）， 且進場一律使用 gsap.from()，所以 JavaScript 或 GSAP 載入失敗時內容仍然可見。

前台代表情境（8）

前台圖形優先、文字精簡。切換上方的方案後，全部情境會以同一組操作重播，方便並排比較。

後台代表情境（7）

後台資訊密度較高，動態必須短、方向明確，且不能讓表格反覆重排。

三套方案共同遵守的限制

  • 只動 transform（x／y／scale）與 opacity；不動 width、height、top、left、margin、box-shadow、filter。
  • 沒有任何 repeat: -1；Donggu 不做無限漂浮。
  • 不使用 ScrollSmoother；本輪也沒有引入任何 GSAP plugin。
  • 表單錯誤只做一次水平提示，並把焦點移到錯誤欄位；錯誤文字與 ARIA 才是主要提示。
  • disabled 或送出中的控制項不會有任何回饋動畫（情境 ④ ⑬ ⑮ 直接示範）。
  • 案件面板維持同層 2/5 : 3/5，只改 opacity 與 x，不改欄寬，因此列表全程不會被遮住；窄畫面上下堆疊，不轉成 modal／drawer。
  • 長列表只有前 N 筆進場，其餘直接顯示（情境 ⑥ 直接示範）。
