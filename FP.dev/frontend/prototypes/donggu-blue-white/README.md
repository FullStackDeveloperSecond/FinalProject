# DoSelect 懂選 — 藍白風格 UI 操作展示原型

這是一份**獨立、可直接開啟**的前端 UI 操作展示原型，用來示範 DoSelect 懂選的瀏覽與操作流程。
本原型**不含任何真實資料、API、資料庫、身分驗證、金流或上傳功能**，所有資料皆為示意用的假資料，重新整理頁面後會重置。

它與 `FP.dev/frontend/customer-web`、`FP.dev/frontend/admin-web` 兩個正式專案完全獨立，未共用任何程式碼或設定。

## 如何開啟

直接用瀏覽器打開（雙擊即可，不需要安裝任何套件或啟動伺服器）：

```
FP.dev/frontend/prototypes/donggu-blue-white/index.html
```

支援以 `file:///` 路徑直接開啟；也可以用任何靜態伺服器開啟，效果相同。

## 畫面清單

頂部導覽列右上角的「☰ 全部畫面」按鈕會展開完整原型導覽選單，可直接跳到任一畫面。

| 畫面 | 說明 |

| 商品詳情 | 商品圖示、價格、適合族群、可展開規格表 |
| 比較商品 | 並排比較已選 2～3 項商品的規格 |
| 購物車／結帳步驟 | 購物車 → 選擇付款 → 完成確認 三步驟示範 |

### 客服流程

| 畫面 | 說明 |
| --- | --- |
| 客服中心 | 客服相關功能入口總覽 |
| FAQ | 分類篩選、關鍵字搜尋、手風琴展開問答 |

## 操作重點

- 「用途選擇 → 預算設定 → 推薦結果」構成新手優先的核心選購流程。
- 每個畫面上方都有「← 上一步」「回首頁」與「目前畫面：〇〇」的提示列，方便隨時掌握所在位置並返回。
- FAQ、客服紀錄詳情、退貨精靈、篩選器等皆為可互動的真實 DOM 操作（展開／收合／切換／表單驗證提示），而非純靜態截圖。
- 所有「送出」動作都只會顯示原型內的示意提示，不會發送任何網路請求。

## 技術說明

- 純 HTML／CSS／JavaScript，無建置流程、無外部套件、無 ES module、無 `fetch`。
- 使用 Hash 路由（例如 `#/products`）切換畫面，狀態存於記憶體，重新整理會重置。
- 視覺系統採用核准的藍白科技風格：白色主底、淺藍表面、深藏青文字、藍色主要按鈕。
- 已加入 `prefers-reduced-motion` 支援、可見的鍵盤焦點樣式、語意化地標（header／nav／main／footer）與 ARIA 屬性。
- Donggu 吉祥物圖片僅作為介面裝飾與導引之用（首頁英雄區、客服中心提示、空狀態插圖等），不做為任何互動邏輯依據。

## 已知限制

- 本原型僅示意畫面流程，非正式系統，因此不含帳號登入、真實金流、真實客服回覆等功能。
- 頁面中的商品、訂單、案件與表單結果皆為操作展示用假資料；重新整理後會回復初始狀態。

## 製作與後續分工

- 本版 HTML 形象 UI 與瀏覽流程由 Codex 直接整理製作，作為畫面審查與討論依據。
- 待前後台需求、資料欄位與畫面流程確認成熟後，再交由實作階段串接正式前後端、資料庫與 API。
- 目前版本已通過 `node --check assets/app.js` JavaScript 語法檢查。
