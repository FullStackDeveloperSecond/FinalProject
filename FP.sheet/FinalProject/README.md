## 文件狀態標記

- `已確認`：可作為設計與實作依據。
- `待確認`：尚未取得團隊決策，不得自行視為需求。
- `延伸目標`：第一版不保證完成。

未完成工作的細部狀態另使用 `⬜ 待辦`、`🔵 進行中`、`🟡 待確認`、`🔴 阻塞`、`⚪ 延後`、`✅ 完成`，統一記錄於 [[05-規劃/未完成項目追蹤表]]。

## 變更原則

1. 商業規則變更時，需同步檢查 API、資料庫、測試與 Demo 文件。
2. 已成立訂單必須保存交易當時的重要規則快照，不可因後台日後修改設定而改變。
3. 所有待辦、待確認、進行中、阻塞、延後與完成項目統一記錄於 [[05-規劃/未完成項目追蹤表]]。
4. 項目完成或狀態改變時，必須同步更新追蹤表；正式決策另寫回所屬文件。
