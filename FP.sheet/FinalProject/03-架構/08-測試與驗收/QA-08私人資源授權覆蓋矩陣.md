# QA-08 私人資源授權覆蓋矩陣

## 文件目的

本矩陣記錄目前已實作 Endpoint 的 Actor A／Actor B、匿名／錯誤角色與拒絕後無副作用證據。它不是未來 Endpoint 的預先驗收結果；新增私人資源、寫入、刪除、附件、匯出、批次或背景操作時，必須在同一個 PR 增列矩陣與測試。

本文件依 [[03-架構/04-安全與檔案/安全與供應鏈強制驗收標準]] 的 SEC-ACC-01～03 執行。

## Actor 定義

| 名稱 | 定義 |
|---|---|
| Actor A | 資源擁有者，或規則明確允許的管理角色／指派處理人 |
| Actor B | 另一位會員、另一個訪客購物車 Key、錯誤管理角色，或不在案件指派範圍內的管理員 |
| 未登入者 | 沒有有效會員／管理員 Session；訪客購物車則以缺少 Guest Cart Key 表示沒有資源憑證 |
| 無副作用 | 拒絕後資料列、數量、狀態、RowVersion、歷程、附件中繼資料及私有檔案維持不變 |

訪客購物車 Key 是該訪客購物車的持有憑證，因此訪客 A／B 隔離以不同 Key 驗證；取得同一 Key 的呼叫者視為持有同一訪客購物車憑證。

## 更新規則

1. 新增或修改私人 Endpoint 的 PR 必須同步更新本矩陣。
2. 每個寫入能力至少新增 Actor B 以 A 的 Route／Parent／Body／Action 識別值呼叫的負面案例，並查核資料庫與外部副作用。
3. 每個刪除能力需包含成功、匿名、錯誤角色／其他使用者、非法狀態、併發；只有實際存在批次能力時才加入批次混入案例。
4. SQL Server 測試納入 Required CI 前，PR 必須附本機完整命令與結果，不得誤寫為 GitHub CI 已執行。
