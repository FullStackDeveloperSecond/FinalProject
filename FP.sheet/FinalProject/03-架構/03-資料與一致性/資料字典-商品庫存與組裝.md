# 資料字典｜商品、庫存與組裝

## 共通欄位 Profile

為避免每表重複列出相同欄位，下列 Profile 是本文件的欄位契約，不是示意：

| Profile | 固定欄位 |
|---|---|
| `Entity` | `Id bigint identity` PK、`PublicId uniqueidentifier` NOT NULL UX、`CreatedAtUtc datetime2(3)` NOT NULL |
| `MutableEntity` | `Entity` 全部欄位＋`UpdatedAtUtc datetime2(3)` NOT NULL＋`RowVersion rowversion` NOT NULL |
| `CodeLookup` | `MutableEntity`＋`Code nvarchar(64)` NOT NULL UX、`NameZhTw nvarchar(160)` NOT NULL、`IsActive bit` NOT NULL default 1、`SortOrder int` NOT NULL default 0 |

所有未特別標示的 FK 採 `Restrict`，並建立 `IX_{Table}_{ForeignKey}`。金額 Check 為 `>= 0`；數量不得為負。系統 Code 先 Trim＋NFKC＋大寫，使用不分大小寫唯一索引。

## 多語系內容

翻譯表只保存顯示內容，不複製價格、庫存、狀態或相容性規格。共同欄位為 `Id bigint identity`、父表 FK、`Locale varchar(10)`、`TranslationStatus varchar(16)`、`ReviewedByAdminUserId nvarchar(450) NULL`、`ReviewedAtUtc datetime2(3) NULL`、`CreatedAtUtc/UpdatedAtUtc datetime2(3)`、`RowVersion rowversion`；Locale 只接受 `zh-TW/ja-JP/ko-KR`，每個父實體＋Locale 唯一。

| Table | 父 FK | 翻譯欄位 |
|---|---|---|
| `BrandTranslations` | `BrandId` | `Name nvarchar(160)`、`Description nvarchar(1000) NULL` |
| `CategoryTranslations` | `CategoryId` | `Name nvarchar(160)`、`Description nvarchar(1000) NULL` |
| `ProductTranslations` | `ProductId` | `Name nvarchar(160)`、`Description nvarchar(4000) NULL` |
| `SkuTranslations` | `SkuId` | `Name nvarchar(160)` |
| `SpecificationDefinitionTranslations` | `SpecificationDefinitionId` | `DisplayName nvarchar(160)`、`HelpText nvarchar(500) NULL` |
| `SpecificationOptionTranslations` | `SpecificationOptionId` | `DisplayName nvarchar(160)` |

`TranslationStatus=MachineDraft/Reviewed/Published`；只有 Published 可作前台內容，缺值依目前語言→繁中→穩定 Key 降級。AI 產生翻譯先存 MachineDraft，管理員確認後才發布。父資料停用不 Cascade 刪除翻譯；匿名化不影響公開型錄翻譯。

`SkuSpecificationOptionSelections` 欄位：`SkuId bigint` FK、`SpecificationOptionId bigint` FK、`SpecificationSourceId bigint NULL` FK、`CreatedAtUtc datetime2(3)`；複合唯一鍵／PK 保證同一 SKU 不會重複選同一 Option。此表只用於 `ValueType=Option && AllowsMultiple=1`，Option 必須屬於該 Definition，SKU Category 必須與 Definition Category 相同。

- `UX_SkuSpecificationValues_SkuId_SpecificationDefinitionId`。
- Check Constraint 依 Definition ValueType 驗證需由 Application 加上資料庫 One-of：單值規格四個 Value 欄恰有一個非 Null；OptionId 指向同一 Definition。多選 Option 不在同一列塞入多值，改由 `SkuSpecificationOptionSelections` 表達。
- SKU 所屬 Product Category 必須與 Definition Category 相同，此跨表規則由 Application／整合測試保證。
- Definition 被使用後 SemanticKey、ValueType、Category、Unit 與 AllowsMultiple 不可改；以停用代替刪除。受保護 Category Code／SemanticKey 組合由程式碼目錄固定。
- 參與功耗、PSU 或其他硬性相容規則的單值或每筆多選關聯都必須有 SpecificationSourceId；原廠資料優先，人工維護與系統估值必須明示 SourceType。核心來源缺失或未覆核時回 `InsufficientData` 並阻擋結帳，不得以 Null 當 0、視為相容或由 AI 猜值。

## 特價

`SalePrices` 使用 MutableEntity：`SkuId bigint` FK、`Price decimal(18,2)`、`StartsAtUtc datetime2(3)`、`EndsAtUtc datetime2(3)`、`Status varchar(16)`、`CreatedByAdminUserId nvarchar(450)`。

- `EndsAtUtc > StartsAtUtc`、Price≥0、Status=`Draft/Scheduled/Active/Cancelled/Expired`。
- `IX_SalePrices_SkuId_StartsAtUtc_EndsAtUtc`；同 SKU 有效期間重疊由 Serializable Transaction／Application 驗證，併發整合測試證明只接受一筆。
- `SalePrices` 是 SKU 特價唯一可寫真實來源；`Skus` 不保存 `SalePrice`，第一版也不建立重複保存活動價格的 `Promotions.SpecialPrice`。
- 訂單不回查 SalePrices；成交價快照在 OrderItem。

## 庫存

| Table／Profile | 額外欄位 | 主要 Constraint／Index | 真實來源／同步 |
|---|---|---|---|
| `InventoryBalances`／MutableEntity | `SkuId bigint`、`OnHandQuantity int`、`ReservedQuantity int`、`AvailableQuantity AS (OnHandQuantity-ReservedQuantity) PERSISTED`、`ReorderLevel int` | `UX_InventoryBalances_SkuId`；OnHand≥0、Reserved≥0、Reserved≤OnHand、Reorder≥0；`IX_InventoryBalances_AvailableQuantity` | derived_balance；Movement／Reservation 同交易更新 |
| `InventoryReservations`／MutableEntity | `SkuId bigint`、`OrderId bigint`、`Quantity int`、`Status varchar(16)`、`ExpiresAtUtc datetime2(3) NULL`、`ReleasedAtUtc datetime2(3) NULL`、`ReleaseReason varchar(32) NULL` | Quantity>0；`IX_InventoryReservations_Status_ExpiresAtUtc`；`IX_InventoryReservations_OrderId_SkuId`；不得保存 CartId | Order-only 保留 Aggregate；Checkout 建立 Order 後於同交易建立並更新 Balance |
| `InventoryMovements`／Entity | `SkuId bigint`、`ReservationId bigint NULL`、`MovementType varchar(32)`、`OnHandDelta/ReservedDelta int`、`BeforeOnHand/AfterOnHand int`、`BeforeReserved/AfterReserved int`、`ReasonCode varchar(32)`、`ReferenceType varchar(32)`、`ReferencePublicId uniqueidentifier NULL`、`ActorUserId nvarchar(450) NULL`、`OccurredAtUtc datetime2(3)` | 不可 Update/Delete；`IX_InventoryMovements_SkuId_OccurredAtUtc`；Before＋Delta=After | append-only 真實異動來源 |
| `InventoryReconciliationCases`／MutableEntity | `SkuId bigint`、`Status varchar(24)`、`ExpectedOnHand/ActualOnHand/ExpectedReserved/ActualReserved int`、`DetectedAtUtc datetime2(3)`、`AcknowledgedBy/ResolvedByAdminUserId nvarchar(450) NULL`、`ResolutionMovementId bigint NULL`、`ResolutionReason nvarchar(1000) NULL`、`ResolvedAtUtc datetime2(3) NULL` | Status=`Open/Acknowledged/Resolved/Dismissed`；同 SKU 最多一個 Open Filtered UX；`IX_InventoryReconciliationCases_Status_DetectedAtUtc` | derived discrepancy；不自動改 Balance |

Cart 不建立 Reservation；價格、庫存與相容性只作預覽並在 Checkout 重驗。Order 刪除不得 Cascade Reservation／Movement；來源失效須走明確 Release。每日核對由 Movement／Reservation 重算期望餘額，差異不得直接覆寫，必須走 Inventory Adjustment。

只有 `InventoryManager`／`SuperAdmin` 可確認或結案差異；修正必須建立 `InventoryMovement` 並回連 `ResolutionMovementId`。`Dismissed` 需說明核對基準錯誤原因，不得用來隱藏未解差異。

| 資料 | 分類 | 同步／延遲 | 重建與防漂移 |
|---|---|---|---|
| Product／Sku／Spec | none | Application 同交易；零延遲 | FK、UX、Check、匯入原子交易 |
