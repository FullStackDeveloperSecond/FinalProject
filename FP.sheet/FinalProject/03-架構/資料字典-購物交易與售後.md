# 資料字典｜購物、交易與售後

本頁沿用 [[03-架構/資料字典-商品庫存與組裝]] 的 `Entity`／`MutableEntity` Profile。所有金額為 `decimal(18,2)`、幣別第一版固定 `TWD`；所有 FK 預設 Restrict。訂單與財務資料不實體刪除。

## 購物車

| Table／Profile | 額外欄位 | Constraint／Index | Delete |
|---|---|---|---|
| `Carts`／MutableEntity | `OwnerUserId nvarchar(450) NULL`、`GuestCartKeyHash binary(32) NULL`、`Status varchar(16)`、`ExpiresAtUtc datetime2(3)` | Owner／Guest Hash 恰一非 Null；`UX_Carts_OwnerUserId_Active` Filtered；`UX_Carts_GuestCartKeyHash_Active` Filtered；Status=`Active/Converted/Expired/Abandoned` | 生命週期清理 |
| `CartItems` | `Id bigint identity`、`PublicId uniqueidentifier`、`CartId bigint`、`SkuId bigint`、`Quantity int`、`AssemblyGroupKey uniqueidentifier NULL`、`CreatedAtUtc/UpdatedAtUtc datetime2(3)`、`RowVersion rowversion` | `UX_CartItems_CartId_SkuId_AssemblyGroupKey`；Quantity 1～99 | Cart Cascade 白名單 |

購物車價格、庫存與相容性只是即時顯示，不保存為成交真實來源；Checkout 必須重新查詢及驗證。

## 訂單與交易快照

### Orders

`Orders` 使用 MutableEntity，欄位如下：

| 群組 | 欄位與型別 | 規則 |
|---|---|---|
| 識別 | `OrderNumber nvarchar(32)`、`MemberUserId nvarchar(450) NULL`、`GuestEmailNormalized nvarchar(320) NULL` | OrderNumber UX；Member／Guest Email 至少一者存在；Email 欄加密或欄位層保護 |
| 狀態 | `OrderStatus/PaymentStatus/FulfillmentStatus/AssemblyStatus/OrderRefundStatus varchar(32)` | 只接受狀態機定義值；訂單退款彙總與單次 RefundTransactionStatus 不得混用 |
| 金額 | `MerchandiseSubtotal/ItemDiscountTotal/ShippingFee/AssemblyFee/GrandTotal/PaidAmount/RefundedAmount decimal(18,2)`、`Currency char(3)` | 全部≥0；GrandTotal=Subtotal-Discount+Shipping+Assembly；Paid／Refunded 受付款交易維護 |
| 收件快照 | `RecipientName nvarchar(100)`、`RecipientPhone nvarchar(32)`、`RecipientEmail nvarchar(320)`、`PostalCode nvarchar(16) NULL`、`RecipientCity nvarchar(50) NULL`、`RecipientDistrict nvarchar(50) NULL`、`AddressLine1 nvarchar(300) NULL`、`AddressLine2 nvarchar(300) NULL` | 宅配時 PostalCode／City／District／AddressLine1 必填；超取需 Store Snapshot；不保存地址簿 Label；依個資 Policy 授權 |
| 物流快照 | `ShippingMethodCode nvarchar(64)`、`ShippingProviderProfileVersionId bigint`、`StoreCode/StoreName/StoreAddress nvarchar(...) NULL`、`ShippingConstraintPolicyVersion int` | 成立後不可被目前設定覆寫 |
| 政策／時間 | `ReturnPolicyVersion int`、`CouponPolicyVersion int NULL`、`PaymentDueAtUtc datetime2(3) NULL`、`ConfirmedAtUtc/PaidAtUtc/ShippedAtUtc/DeliveredAtUtc/CompletedAtUtc/CancelledAtUtc datetime2(3) NULL` | 依合法狀態轉移填入；一般宅配與超取可依金額／商品限制使用 COD，組裝電腦宅配必須先付款 |
| 冪等 | `CheckoutIdempotencyKey nvarchar(128)`、`SourceCartPublicId uniqueidentifier NULL` | Idempotency UX；同會員／訪客 Scope 不可重複建單 |

索引：`UX_Orders_OrderNumber`、`UX_Orders_CheckoutIdempotencyKey`、`IX_Orders_MemberUserId_CreatedAtUtc`、`IX_Orders_OrderStatus_PaymentDueAtUtc`、`IX_Orders_CompletedAtUtc`。個資查詢不得加入一般全文索引。

### OrderItems

`OrderItems` 使用 Entity，另有：`OrderId bigint`、`SkuId bigint NULL`、`SkuCodeSnapshot nvarchar(64)`、`ProductNameSnapshot nvarchar(160)`、`SkuNameSnapshot nvarchar(160)`、`Quantity int`、`ListUnitPrice/SaleUnitPrice/FinalUnitPrice/UnitCostSnapshot/LineSubtotal/DiscountAllocation/LineTotal decimal(18,2)`、`AssemblyGroupKey uniqueidentifier NULL`、`ReturnableQuantity int`、`ReturnedQuantity int`。

- Quantity>0；金額與數量一致；Returned≤Returnable≤Quantity。
- `IX_OrderItems_OrderId`、`IX_OrderItems_SkuId`、`IX_OrderItems_OrderId_AssemblyGroupKey`。
- SKU FK 可在未來資料歸檔後為 Null，但快照欄永遠保留；第一版 SKU 不實體刪除。

## 優惠券

| Table／Profile | 額外欄位 | Constraint／Index |
|---|---|---|
| `Coupons`／MutableEntity | `Code nvarchar(64)`、`NameZhTw nvarchar(160)`、`DiscountType varchar(16)`、`DiscountValue decimal(18,2)`、`MinimumSpend decimal(18,2)`、`MaximumDiscount decimal(18,2) NULL`、`StartsAtUtc/EndsAtUtc datetime2(3)`、`TotalUsageLimit/PerMemberLimit int NULL`、`MemberOnly bit`、`ExcludeSaleItems bit`、`ScopeType varchar(16)`、`Status varchar(16)` | Code UX；Ends>Starts；百分比使用 DiscountValue 0～1；限制>0；ScopeType=`All/Restricted` |
| `CouponCategories`／Join | `CouponId bigint`、`CategoryId bigint`、`CreatedAtUtc datetime2(3)` | 複合 PK `(CouponId,CategoryId)`；兩 FK Restrict |
| `CouponProducts`／Join | `CouponId bigint`、`ProductId bigint`、`CreatedAtUtc datetime2(3)` | 複合 PK `(CouponId,ProductId)`；兩 FK Restrict |
| `CouponExcludedProducts`／Join | `CouponId bigint`、`ProductId bigint`、`CreatedAtUtc datetime2(3)` | 複合 PK `(CouponId,ProductId)`；兩 FK Restrict |
| `CouponRedemptions`／Entity | `CouponId bigint`、`OrderId bigint`、`MemberUserId nvarchar(450) NULL`、`GuestUsageKeyHash binary(32) NULL`、`Status varchar(16)`、`ReservedAtUtc datetime2(3)`、`ExpiresAtUtc/ReleasedAtUtc/ConsumedAtUtc datetime2(3) NULL` | `UX_CouponRedemptions_CouponId_OrderId`；MemberUserId／GuestUsageKeyHash 恰一非 Null；`IX_CouponRedemptions_CouponId_Status`；只在 Checkout 建單交易建立，使用名額以 Serializable 或等價原子條件取得 |
| `OrderCoupons`／Entity | `OrderId bigint`、`CouponId bigint NULL`、`CouponCodeSnapshot nvarchar(64)`、`NameSnapshot nvarchar(160)`、`RuleVersion int`、`DiscountType varchar(16)`、`DiscountValue/AppliedAmount decimal(18,2)` | 每張訂單最多一筆；`UX_OrderCoupons_OrderId`；若有 Redemption，其 OrderId／CouponId 必須與本快照相符；transaction_snapshot |

`ScopeType=All` 不得建立包含範圍；`ScopeType=Restricted` 至少要有一筆 `CouponCategories` 或 `CouponProducts`。`CouponExcludedProducts` 的排除結果優先於分類或商品包含規則；同商品不得同時存在於 `CouponProducts` 與 `CouponExcludedProducts`，由同一交易的 Application 驗證與整合測試保證。範圍不得保存為自由文字或任意 JSON。

優惠券部分退貨不回查 Coupons；依 OrderCoupon 與 OrderItem DiscountAllocation 快照計算。

訪客每人使用限制以伺服器 Secret 對正規化訂單 Email 計算 HMAC-SHA-256，僅保存 `GuestUsageKeyHash`；不得保存、回傳或反解 Email 副本。V1 固定 Secret Version 1，Secret 不進儲存庫；未來輪替前須先定版版本欄位與相容查詢規則。

## 正規化審核摘要

| 資料 | 分類 | 同步／延遲 | 重建與防漂移 |
|---|---|---|---|
| Cart | none | 即時 | UX、RowVersion、Checkout 重驗證 |
| Order／OrderItem 快照 | transaction_snapshot | 建單交易內；零延遲 | 金額 Check、付款／退款對帳、歷史快照測試 |
| Order 主狀態 | 顯示 current state | 與 StatusHistory 同交易 | 由最後合法 History 核對；不可任意改寫 |
| Coupon 使用數 | none＋交易計數 | Reservation 同交易 | CouponRedemption 查詢核對 |
| Payment／Refund | append event＋current state | Event 冪等交易 | ExternalEventId、IdempotencyKey、金額對帳 |
| Shipping 設定／訂單物流 | 主資料＋transaction_snapshot | 建單時快照 | Profile Version FK 與 Shipment 對帳 |

第一版不建立交易報表彙總表；報表直接由上述索引與交易真實來源查詢。
