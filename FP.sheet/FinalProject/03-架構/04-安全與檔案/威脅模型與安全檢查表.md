# 威脅模型與安全檢查表

## 範圍與資產

保護對象包括會員與管理員帳號、TOTP 與 Recovery Codes、訂單與收件快照、付款／退款狀態、庫存、客服內容與附件、AI 同意與對話紀錄、稽核日誌、API Key、SMTP 憑證及 SQL Server 資料。

第一版的信任邊界：

```text
瀏覽器（customer-web／admin-web）
        ↓ HTTPS／Cookie／Anti-forgery
ASP.NET Core API
   ├─ Application／Domain
   ├─ SQL Server／Hangfire
   ├─ 本機私有檔案目錄／Defender
   ├─ Brevo SMTP
   └─ OpenAI API
```

現場雖為本機展示，仍必須把瀏覽器輸入、AI 輸出、上傳檔案及模擬 Provider 回呼視為不可信資料。

## 主要威脅與對策

| ID | 類型 | 風險情境 | 必要對策 | 驗收證據 |
|---|---|---|---|---|
| TM-01 | Spoofing | 會員 Cookie 被拿來操作管理 API，或管理員繞過 2FA。 | 會員／管理員 Cookie Scheme 隔離；管理 API 同時驗證管理員身分、2FA 與角色。 | Scheme 交叉使用、未完成 2FA 的負面測試 |
| TM-02 | Spoofing | 訪客猜測訂單編號後查看他人訂單。 | 訂單編號＋購買 Email 只觸發一致回應；完成一次性驗證後核發只綁定單筆訂單的短效權杖。 | 不存在／錯誤 Email 不洩漏、跨訂單存取測試 |
| TM-03 | Tampering | 前端修改價格、折扣、組裝費、運費、角色或庫存。 | API 只接受識別碼與允許輸入；後端重新計價、重新授權並在交易中驗證庫存。 | 竄改 Request 的整合測試 |
| TM-04 | Tampering | 重複送出建立訂單、付款回呼、退款或背景工作造成雙重副作用。 | 冪等鍵、唯一約束、交易、工作冪等與可辨識的重複結果。 | 重送與併發整合測試 |
| TM-05 | Repudiation | 管理員否認查看個資、釋放庫存、出貨、退款或改權限。 | 不可由一般文字 Log 取代的 `AuditLog`；保存 actor、前後值、時間、IP 與 TraceId。 | 稽核查詢與缺欄位檢查 |
| TM-06 | Information Disclosure | API 回傳完整會員 Entity、其他人的訂單或過多收件資料。 | 使用目的別 DTO、資源所有權授權、遮蔽欄位；`OrderManager` 僅看履約所需訂單快照。 | DTO 快照與越權負面測試 |
| TM-07 | Information Disclosure | Secret、連線字串、OpenAI Key 或 SMTP 憑證進入 Git／Log。 | 使用本機 Secret 與環境設定；Log 遮蔽；提交前 Secret 掃描；範例設定只含鍵名。 | Repository 掃描與 Log 檢查 |
| TM-08 | Information Disclosure | 客服、檢舉或退貨附件可由靜態網址直接下載。 | 檔案置於網站根目錄外；下載經授權 API；以伺服器檔名保存，不信任原始檔名。 | 未登入、跨案件、路徑穿越測試 |
| TM-09 | Elevation of Privilege | 只靠 Vue Router Guard 隱藏按鈕，使用者直接呼叫高權限 API。 | 每個 Application Use Case 與 Endpoint 執行角色／Policy 及資源範圍檢查。 | 各角色 View/Create/Edit/Approve 負面矩陣 |
| TM-10 | Denial of Service | 登入、Email 驗證、忘記密碼、訪客訂單驗證或 AI API 被大量呼叫。 | 每帳號／IP／用途限制、冷卻時間、用量配額、工作佇列與一致的非列舉錯誤。精確數值由相關契約決定。 | 限流、鎖定及恢復測試 |
| TM-11 | File Upload | 偽造副檔名、惡意內容、超大檔案或掃描服務失敗。 | 大小／數量、MIME、檔案簽章與允許格式驗證；暫存後由 Defender 掃描；未知結果 Fail Closed。 | EICAR／偽 MIME／超限／掃描不可用測試 |
| TM-12 | CSRF／CORS | 惡意網站利用已登入 Cookie 發送寫入請求。 | 明列 Origin、不使用萬用 Origin 搭配 Credentials；寫入請求驗證 Anti-forgery Token。 | 惡意 Origin、缺 Token、錯 Token 測試 |
| TM-13 | XSS／Injection | 商品、評價、客服內容或 Excel 儲存惡意 HTML／公式；查詢值進入 SQL。 | Vue 預設轉義；禁止未清理的 `v-html`；EF 參數化查詢；Excel 匯出防公式注入；輸入長度與格式驗證。 | 常見 payload、公式前綴與查詢測試 |
| TM-14 | Callback／Replay | 模擬付款或物流回呼被偽造、重播、亂序。 | 驗證回呼來源、完整性與新鮮度；事件 ID 去重；狀態機拒絕非法或倒退轉移。精確簽章方式於 Provider 契約決定。 | 偽造、重播、過期、亂序測試 |
| TM-15 | Prompt Injection | 商品文字、FAQ 或顧客訊息要求 AI 洩漏系統提示、個資或執行操作。 | 系統指令與不可信內容分離；只提供白名單工具；工具在後端授權；AI 不具寫入工具；輸出再驗證。 | Prompt Injection 與工具越權資料集 |
| TM-16 | AI Data Leakage | AI 取得完整個資、他人訂單或其他顧客客服歷史。 | 後端先驗證當前會員所有權、最小化與去識別化；客服歷史只屬於當前案件／會員；送出前建立可測試的資料投影。 | 姓名、Email、電話、地址、他人訂單負面測試 |
| TM-17 | AI Hallucination | AI 虛構價格、庫存、相容性、退貨政策或訂單狀態。 | AI 只解析與解釋；價格、庫存、相容性與訂單狀態由後端確定性資料決定；答案附資料來源或轉人工。 | 過期資料、不相容與無結果案例 |
| TM-18 | Log Abuse | 攻擊者以換行或敏感內容污染 Log，或一般管理員查閱敏感 Log。 | 結構化日誌、欄位清理、敏感值遮蔽、查閱權限及保存政策。 | Log injection 與權限測試 |
| TM-19 | Concurrency | 最後庫存、優惠券次數、設定版本或狀態被同時修改。 | SQL Server 交易、條件更新、唯一約束與 `rowversion`；衝突回傳穩定 409。 | 併發整合測試 |
| TM-20 | Recovery | 展示前資料損壞、重設腳本誤覆蓋 Secret，或背景工作停在半途。 | 可重建 Migration／Seed、設定與資料分離、重試及可診斷狀態；採 RPO 24 小時、RTO 2 小時及既定 Backup Set／Manifest。 | 重建與復原演練 |

## 開發完成檢查表

### 身分與授權

- [ ] 會員與管理員 Cookie 無法交叉存取受保護 API。
- [ ] 管理員未完成 TOTP 時無法進入管理功能。
- [ ] 每個訂單、退貨、退款、客服及附件 API 都測試資源所有權。
- [ ] 每種私人資源都有 User A／User B 的明細、列表、搜尋、匯出、附件及 AI／背景結果越權讀取負面測試。
- [ ] 每個修改與 Action Endpoint 都有替換路由 ID、Body ID、Parent ID 及批次列的跨使用者負面測試，且拒絕後無資料或副作用變更。
- [ ] 每個 Hard／Soft／附件／批次刪除都在伺服器端異動前驗證角色、Actor Scope、資源所有權及業務狀態；前端確認視窗不作為授權證據。
- [ ] 角色矩陣中的禁止操作均有至少一個負面測試。
- [ ] 登出、停權、密碼重設與角色變更會依正式生命週期使工作階段失效。

### 輸入、輸出與檔案

- [ ] Request 有長度、格式、範圍與允許值驗證。
- [ ] Response 不直接序列化 EF Core Entity。
- [ ] 上傳檔案通過大小、數量、簽章、MIME 與 Defender 驗證。
- [ ] 下載只能透過授權 API，且無路徑穿越。
- [ ] Excel 匯入不信任公式、隱藏列、額外欄位或偽裝資料型別。

### 商業交易與背景工作

- [ ] 訂單、付款、退款、庫存與優惠券具有冪等及併發測試。
- [ ] 模擬 Provider 回呼能拒絕偽造、重播、過期及非法狀態。
- [ ] Hangfire 工作可以重試且不重複扣庫存、寄信或退款。
- [ ] Dashboard 只能由之後選定的管理角色存取。

### AI 與個資

- [ ] OpenAI Request 的測試快照不含姓名、Email、電話、地址或未授權訂單。
- [ ] AI 沒有任何取消、退貨、退款或資料修改工具。
- [ ] Structured Output 必須通過 Schema 與後端商業驗證才可使用。
- [ ] 使用者拒絕 AI、AI 逾時、限流或輸出不合法時能安全降級。
- [x] Prompt Injection、跨會員訂單與客服歷史隔離已加入 120 筆版本化評估資料集；案例仍須完成 Terry／Kafen 主標、Alex 第二審與發布核准。

### Secret、日誌與復原

- [ ] Repository 與建置產物不含 Secret。
- [ ] 每次 Commit／PR 都檢查工作樹、Staged／PR Diff、設定範例、測試快照與 Vue Production Bundle，不含真實 API Key、密碼、Token、私鑰或含密碼連線字串。
- [ ] 新增的 NuGet／npm Package 已由正式 Registry 解析，精確名稱與版本可對應官方來源，乾淨 Restore／Install、Lock File 與漏洞掃描均通過。
- [ ] Log 不記錄密碼、Token、完整 Cookie、TOTP Seed、Recovery Code 或完整個資。
- [ ] 高風險操作可由 `TraceId` 串接 HTTP、背景工作與 `AuditLog`。
- [ ] 空白資料庫重建、Seed 重設及失敗復原至少演練一次。
