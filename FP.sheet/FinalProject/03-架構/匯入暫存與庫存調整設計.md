# 匯入暫存與庫存調整設計

## 匯入類型

| 類型 | 資料集 | 是否改庫存 |
|---|---|---:|
| 商品匯入 | Product、SKU、Specification | 否 |
| 庫存匯入 | Inventory Adjustment | 是；只經調整流程 |

兩者使用相同的 Preview／Confirm 概念，但權限、驗證及提交 Use Case 分開。

## ImportBatch

預覽資料保存 24 小時。Batch 至少需要：

- UUID v7 PublicId、Import Type、Template Version、Status。
- 建立者 Admin PublicId、建立與到期時間。
- 三份來源檔案 Hash、檔名的安全顯示值與資料列數。
- 新增、更新、無變更、錯誤統計。
- 正規化後內容版本與 RowVersion。
- ConfirmedAtUtc、結果摘要與 Correlation ID。
- 單一檔案上限 10 MB、5,000 列。
- 同一管理員每種 Import Type 同時只允許一個未結束 Batch；商品與庫存可各有一批。

狀態骨架：

```text
Uploaded
→ Validating
→ Ready | Invalid
→ Committing
→ Committed | Failed | Expired
```

Committed 不可重送；Failed 必須以修正後檔案建立新 Batch。

## ImportRow

- 保存資料集、來源列號、穩定匯入鍵、Action、正規化後最小 Payload、Error Codes 與 Row Hash。
- 不把原始 Excel／CSV 任意公式或巨量文字直接保存為可信資料。
- Product／SKU／Specification 以穩定匯入鍵與 SKU Code 關聯；不能以名稱猜測。
- 預覽畫面只讀 ImportRow；修改來源內容需重新上傳並產生新 Batch，避免預覽與提交內容不同。
- 查詢與錯誤使用正規化欄位；原始列另存具 Schema Version、最多 32 KB 的 Raw JSON，只供短期預覽及除錯，不得含 Secret 或不必要個資。

## CSV 格式

- UTF-8 with BOM、逗號分隔、雙引號跳脫、固定英文 Header。
- Null Token 固定 `\N`；空欄代表空字串，兩者不可互換。
- 日期時間使用 ISO 8601；Decimal 使用 `.`；Boolean 與 Enum 使用固定英文 Token。
- 系統 Code Trim 後正規化為大寫；一般字串 Trim＋Unicode NFKC。
- 任何未知、缺少、重複或順序不符合契約的 Header 整批拒絕，不自動猜測語系。

## 商品模板 v1 欄位契約

XLSX 工作表名稱固定為 `Products`、`Skus`、`Specifications`；CSV 則分成三個同名邏輯資料集。欄位順序必須與下表一致。三個資料集合計最多 5,000 筆資料列；XLSX 單檔或每個 CSV 單檔上限 10 MB。

### Products

| Header | 型別／上限 | 必填 | 規則 |
|---|---|:---:|---|
| `product_key` | String(64) | ✓ | 批次內穩定關聯鍵；Trim 後大寫，同批唯一 |
| `product_code` | String(64) | ✓ | 商品不可變代碼；既有值更新，不存在值新增 |
| `name_zh_tw` | String(160) | ✓ | 繁中顯示名稱 |
| `brand_code` | String(40) | ✓ | 必須引用啟用中的 Brand |
| `category_code` | String(40) | ✓ | 必須引用啟用中的 Category |
| `description_zh_tw` | String(4000) |  | `\N` 表示 Null |
| `warranty_months` | Int32, 0～120 |  | `\N` 表示未提供 |
| `status` | Enum | ✓ | `Draft`、`Published`、`Unpublished` |

### Skus

| Header | 型別／上限 | 必填 | 規則 |
|---|---|:---:|---|
| `sku_key` | String(64) | ✓ | 批次內穩定關聯鍵，同批唯一 |
| `sku_code` | String(64) |  | 空字串表示新增並由系統產碼；既有代碼精確更新且不可改碼 |
| `product_key` | String(64) | ✓ | 引用本批 Products 或同代碼既有 Product |
| `name_zh_tw` | String(160) | ✓ | 規格／變體顯示名稱 |
| `list_price` | Decimal(18,2) | ✓ | 大於或等於 0 |
| `sale_price` | Decimal(18,2) |  | `\N` 表示無常態售價覆寫；不得高於 `list_price` |
| `unit_cost` | Decimal(18,2) | ✓ | 大於或等於 0；只供授權後台使用 |
| `weight_kg` | Decimal(10,3) |  | `\N` 或大於 0 |
| `length_cm` | Decimal(10,2) |  | `\N` 或大於 0 |
| `width_cm` | Decimal(10,2) |  | `\N` 或大於 0 |
| `height_cm` | Decimal(10,2) |  | `\N` 或大於 0 |
| `status` | Enum | ✓ | `Draft`、`Published`、`Unpublished` |

### Specifications

| Header | 型別／上限 | 必填 | 規則 |
|---|---|:---:|---|
| `sku_key` | String(64) | ✓ | 引用本批 Skus |
| `semantic_key` | String(64) | ✓ | 引用該分類啟用中的 Specification Definition |
| `value_type` | Enum | ✓ | `String`、`Decimal`、`Boolean`、`Option` |
| `string_value` | String(500) | 條件 | `String` 時唯一非 Null 值欄 |
| `decimal_value` | Decimal(18,4) | 條件 | `Decimal` 時唯一非 Null 值欄 |
| `boolean_value` | Boolean | 條件 | `true`／`false` |
| `option_code` | String(64) | 條件 | `Option` 時引用既有選項 |

同一 `sku_key + semantic_key` 只允許一列。值型別必須符合規格定義，四個值欄只有對應型別欄可有值；非對應欄必須使用 `\N`。

### Inventory Adjustments

庫存不與商品模板混用，獨立模板 Header 固定如下：

| Header | 型別／上限 | 必填 | 規則 |
|---|---|:---:|---|
| `sku_code` | String(64) | ✓ | 必須是既有 SKU |
| `target_on_hand` | Int32 | ✓ | 0～2,147,483,647 |
| `reason_code` | Enum | ✓ | 只接受本文件列出的六個原因碼 |
| `note` | String(500) | 條件 | `Other` 必填，其餘可為 `\N` |

## API 契約

| Method／Route | 用途 | Policy |
|---|---|---|
| `GET /api/v1/admin/import-templates/products/current` | 下載目前 XLSX／CSV 模板與版本資訊 | `CatalogImport.Read` |
| `POST /api/v1/admin/product-imports/preview` | 上傳 XLSX，或三份 CSV 加 `templateVersion` | `CatalogImport.Execute` |
| `GET /api/v1/admin/product-imports/{id}` | 查詢 Batch、統計與 RowVersion | 建立者或 `CatalogImport.ReadAll` |
| `GET /api/v1/admin/product-imports/{id}/rows` | Cursor 分頁查看預覽列與錯誤 | 建立者或 `CatalogImport.ReadAll` |
| `GET /api/v1/admin/product-imports/{id}/errors` | 下載防公式注入後的錯誤 CSV | 建立者或 `CatalogImport.ReadAll` |
| `POST /api/v1/admin/product-imports/{id}/confirm` | 傳入 RowVersion 後原子提交 | 建立者且具 `CatalogImport.Execute` |
| `POST /api/v1/admin/inventory-imports/preview` | 上傳庫存調整模板 | `InventoryAdjust.Execute` |
| `POST /api/v1/admin/inventory-imports/{id}/confirm` | 驗證 Balance RowVersion 後提交 | `InventoryAdjust.Execute` |

Preview 回應 `202 Accepted` 並提供 Batch PublicId；狀態查詢回傳各 Action 統計。Confirm 成功回 `200` 與提交摘要，重送已提交 Batch 回 `409 import_already_committed`，過期回 `410 import_batch_expired`，欄位／資料錯誤回穩定列級錯誤碼。

## 商品匯入確認

1. 以 Batch PublicId、管理員身分與 RowVersion 取得 PreviewReady Batch。
2. 驗證 Batch 未到期、尚未提交、Template 仍受支援，三檔 Hash 未改變。
3. 重新驗證目前 Brand／Category／Specification Definition／SKU 狀態。
4. 在單一 SQL Server 交易執行全部 Product／SKU／Specification 更新。
5. 任一列失敗整批回滾，Batch 記錄安全錯誤；不產生部分成功。
6. 寫入 AuditLog 與必要 Outbox，Commit 後將 Batch 標為 Succeeded。

## 庫存匯入確認

- 每列輸入 SKU Code、盤點後目標 `OnHand`、原因碼與說明；Preview 依目前 Balance 計算 Adjustment Delta。
- Commit 檢查 Preview 時的 Balance RowVersion；任一 SKU 已變動時整批拒絕並要求重新 Preview。
- 原因碼包含 `StocktakeDifference`、`Damaged`、`Lost`、`ReturnRestock`、`DataCorrection`、`Other`；`Other` 必填說明。
- 每批單一交易，任一錯誤整批回滾。
- 每列產生 Adjustment InventoryMovement，並同交易更新 InventoryBalance。
- 不允許造成負 OnHand、負 Reserved、Reserved 大於 OnHand，或覆蓋 Active Reservation。
- 所有列都保存 Before、Delta、After、Reason、Actor、Batch PublicId 及時間。

## 安全與清理

- Preview／Confirm 只允許建立者或具匯入管理權限者；不得只靠前端隱藏按鈕。
- 來源檔先做大小、格式、檔案簽章與必要惡意內容檢查；公式不執行。
- Committed Batch 摘要與結果保存 90 天；ImportRow／Raw JSON 在提交後最多保存 24 小時。
- Invalid、Failed、Expired 的錯誤列保存 24 小時供下載修正，Batch 摘要保存 90 天。
- 清理由 `maintenance` Queue 執行；正式領域資料與 AuditLog 是長期稽核來源。
- Log 不記錄整列個資或完整檔案內容。
