# DoSelect 懂選｜專案概述

狀態：已確認

## 專案識別

- 正式中文名稱：`懂選`
- 正式英文名稱：`DoSelect`
- 完整顯示名稱：`DoSelect 懂選`
- 商業標語：`說出需求，組出適合你的電腦。`

## 專案背景

本專案為五人小組的畢業專題，開發與文件、測試、簡報、彩排的總期間約為 40 天。每位成員每週可投入約 30 小時，五位成員皆參與開發。

專案只需在現場由團隊操作展示，不需要正式部署至公網。展示環境預計由一台電腦執行 SQL Server、ASP.NET Core API、Vue 消費者前台與 Vue 管理後台，現場可使用網路。

## 評定方向

評定人員以企業 HR 為主，專題重點為商業價值與問題解決能力，而非展示大量程式碼或單純堆疊功能。

## 目標市場

- 商業型態：台灣單一商家 B2C 電商。
- 商品類型：實體電腦商品。
- 幣別：新台幣。
- 主要客群：電腦組裝新手。
- 次要客群：專業創作者。
- 整體市場：一般消費者、遊戲玩家、公司採購及其他需要電腦產品的使用者。

## 核心問題

許多使用者知道自己的預算與用途，卻不熟悉 CPU、顯示卡、主機板、記憶體、電源等專業規格，因此必須先花大量時間研究，仍可能購買不相容或不符合需求的商品。

## 價值主張

> 讓只知道預算與用途、卻不熟悉硬體規格的消費者，透過自然語言描述需求，快速獲得可解釋、彼此相容且有庫存的電腦與零件組合，降低選購時間與錯配風險。

## 核心亮點

1. 使用自然語言搜尋商品並取得可解釋的 AI 推薦。
2. 由確定性的後端規則驗證零件相容性，AI 不作為最終判定者。
3. 支援自由組裝電腦、儲存與分享組裝清單。
4. 提供完整的訪客購買、付款模擬、庫存保留、物流、退貨與部分退款流程。
5. AI 客服能在取得同意後，使用去識別化資料回答會員自己的訂單問題，無法處理時轉人工客服。
6. 後台提供角色分工、稽核紀錄與營運報表。

## 核心技術

- SQL Server 2025 Developer Edition
- ASP.NET Core 10 Web API
- Entity Framework Core
- Vue.js 3
- TypeScript
- Vite
- 前後端分離
- 消費者前台與管理後台各自為 Vue 應用程式
- OpenAI API

## 開發限制

- 目前專案從空白開始。
- 第一版不使用 Docker。
- 消費者前台 M 範圍以桌面版完成核心流程；手機與平板 RWD 為 S，達到 S 啟動門檻後才實作與驗收。
- 管理後台第一版只需桌面版。
- 金流與物流使用邏輯正確、可替換真實服務的模擬 Provider，不串接真實業者。
- Email 驗證與通知需要實際寄送。
- 取消手機登入與 SMS 驗證。
- 管理員使用 TOTP 雙因素驗證，支援 Google Authenticator 等相容 App。
