# 商品、組裝與相容性

狀態：已確認

## 商品目錄

第一版商品目錄包含：

- 商品
- SKU 與商品變體
- 品牌
- 分類
- 標籤
- 商品規格
- 多張商品圖片及排序
- 草稿、上架、下架狀態
- 售價及特價
- 搜尋與篩選
- 庫存狀態

商品範圍包含單一電腦零件、周邊商品、品牌套裝電腦及自由組裝電腦。

### 後台批次操作與 Excel

優先級：M。

- 商品列表支援批次上架、批次下架及批次調價。
- 支援將商品資料匯出為 Excel。
- 支援透過 Excel 批次建立或更新商品。
- 匯入欄位必須能對應分類及規格範本。
- 匯入欄位契約、驗證結果格式、部分成功、交易回滾及重複資料處理仍待確認，不得由開發者自行假定。

## 第一版組裝零件

| 零件 | 必要規格範例 |
|---|---|
| CPU | Socket、世代、功耗、內顯 |
| 主機板 | Socket、晶片組、支援 CPU 世代、RAM 類型、尺寸及插槽 |
| 記憶體 | DDR 世代、容量、頻率及套件數量 |
| 顯示卡 | 長度、建議電源瓦數及供電接頭 |
| SSD/HDD | 介面、尺寸及容量 |
| 電源供應器 | 額定瓦數、供電接頭及尺寸 |
| 機殼 | 支援主機板尺寸、顯示卡長度、散熱器高度及電源尺寸 |
| CPU 散熱器 | 支援 Socket、高度及散熱能力 |

螢幕、鍵盤、滑鼠等周邊不參與整機主要相容性驗證。

## 分類與規格範本

- 管理員可以動態新增、修改及刪除所有商品規格欄位。
- 不同分類使用各自的規格範本，新增或編輯商品時依分類顯示對應欄位。
- 規格欄位至少需要穩定識別碼、顯示名稱、資料型別、是否必填、排序及啟用狀態；其精確資料設計仍待完成。

> [!warning] 動態規格與相容性程式的設計衝突
> 相容性必要欄位仍必須保存為可驗證的結構化資料，但管理員可以動態修改所有欄位。欄位刪除、改名或變更型別時如何維持固定相容性程式尚未確認；此衝突解決前不得完成資料表、Excel 契約或相容性 API。

## 相容性規則

第一版必須驗證：

1. CPU Socket 與主機板 Socket 相同。
2. 主機板晶片組支援 CPU 世代。
3. 主機板目前 BIOS 相容性資料允許該 CPU；具體 BIOS 版本管理深度仍待確認。
4. 主機板與記憶體 DDR 世代相同。
5. 記憶體數量不超過主機板插槽數。
6. 記憶體總容量不超過主機板支援上限。
7. 主機板尺寸能安裝於機殼。
8. 顯示卡長度不超過機殼限制。
9. 散熱器支援 CPU Socket。
10. 散熱器高度不超過機殼限制。
11. 儲存裝置介面有對應主機板插槽。
12. 電源額定瓦數符合整機預估負載與安全餘裕。
13. 電源具有必要供電接頭。

必要規格應使用結構化欄位，不得只保存成人類描述文字。其他展示型規格可以使用較彈性的規格資料。

### 相容性規則後台

- 相容性規則程式由開發者維護，管理員不能在後台新增、修改或刪除規則程式。
- 管理員可以查看現有規則。
- 管理員可以啟用或停用規則允許調整的設定值。
- 管理員可以選擇商品或 SKU 執行規則測試並查看結果。
- 可設定值的範圍、測試資料保存方式及操作權限仍待確認。

## AI 推薦流程

```text
使用者輸入自然語言需求
→ AI 擷取預算、用途、規格與品牌偏好
→ 後端查詢上架且有庫存的候選 SKU
→ 後端相容性規則驗證
→ 排序候選組合
→ AI 只針對已驗證結果產生推薦理由
```

推薦必須：

- 說明推薦原因。
- 顯示預算使用情況。
- 不推薦下架或不可售商品。
- 不把 AI 文字聲明當作相容性保證。
- AI 不可用時改用一般關鍵字搜尋與篩選。

## 組裝清單

組裝清單包含：

```text
BuildConfiguration
├─ BuildConfigurationItem
└─ CompatibilityCheckResult
```

規則：

- 會員可以將組裝清單保存到伺服器並跨裝置存取。
- 訪客使用瀏覽器本地儲存保存草稿。
- 訪客登入後可以將本地清單匯入會員帳號。
- 組裝清單可以產生不可預測、唯讀的分享連結。
- 分享頁不得包含建立者姓名、Email、購物車、訂單或會員資料。
- 分享清單可複製，不可修改原建立者清單。
- 每次開啟分享頁都重新驗證價格、庫存、上下架及相容性。
- 組合內任何必要零件缺貨或不可售時，整組不能直接結帳，必須先更換零件。

## 加入購物車

組裝電腦在畫面上以群組顯示，但底層保留每一個 SKU：

```text
自訂電腦組合
├─ CPU SKU
├─ 主機板 SKU
├─ 記憶體 SKU
├─ 顯示卡 SKU
├─ 儲存裝置 SKU
├─ 電源 SKU
├─ 機殼 SKU
├─ 散熱器 SKU
└─ 組裝服務費 NT$300
```

每一台實際組裝電腦收取一次 NT$300。例如同一訂單購買三台組裝電腦，組裝費為 NT$900。

## 組裝生命週期

```text
Draft
→ Submitted
→ Paid
→ AssemblyPending
→ AssemblyStarted
→ Testing
→ ReadyToShip
→ Shipped
```

- `AssemblyStarted` 之前可以取消。
- 開始組裝後不接受無理由取消，但瑕疵、規格錯誤或組裝錯誤仍需處理。
