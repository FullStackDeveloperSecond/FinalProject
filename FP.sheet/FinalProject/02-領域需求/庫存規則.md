# 庫存規則

狀態：已確認

## 庫存模型

單一倉庫，SKU 至少保存：

```text
OnHandQuantity
ReservedQuantity
AvailableQuantity = OnHandQuantity - ReservedQuantity
ReorderLevel
RowVersion
```

- `OnHandQuantity`：倉庫內實際數量。
- `ReservedQuantity`：已被未完成訂單保留的數量。
- `AvailableQuantity`：目前可售數量。
- 銷售數量由訂單與出貨紀錄統計，不作為第三個實體庫存桶。

## 購物車

- 加入購物車前檢查商品上架狀態與可售庫存。
- 購物車開啟、修改數量及結帳前重新檢查。
- 商品缺貨、下架、價格改變時更新購物車狀態並提示使用者。
- 購物車不保留庫存。

## 建立訂單

防止超賣的最後防線位於後端資料庫交易：

```text
開始交易
→ 重新查詢各 SKU 可售庫存
→ 原子增加 ReservedQuantity
→ 建立訂單及保留紀錄
→ 成功提交
```

若多人同時購買最後一件商品，只有一筆交易能成功；另一筆回傳庫存不足或 HTTP 409。不得依賴前端即時更新來保證庫存正確。

## 保留期限

| 付款方式 | 保留期限 |
|---|---:|
| 信用卡 | 15 分鐘 |
| LINE Pay | 15 分鐘 |
| Apple Pay | 15 分鐘 |
| Google Pay | 15 分鐘 |
| ATM | 3 天 |
| 超商代碼 | 3 天 |
| 貨到付款 | 訂單直接確認，不等待付款 |

Demo 環境可透過設定將短期保留縮短為 2 至 3 分鐘，以展示逾時釋放，但正式規則仍保存上述預設值。

## 庫存狀態改變

```text
建立訂單：ReservedQuantity 增加
取消／付款逾時：ReservedQuantity 減少
出貨：OnHandQuantity 與 ReservedQuantity 同時減少
訂單完成：不再修改實體庫存
```

## 逾時取消

- 背景排程自動取消逾時訂單並釋放保留庫存。
- 管理員也能在符合條件時人工執行。
- 兩種方式都必須確保冪等，重複執行不能重複釋放。
- 每次保留、釋放、出貨及人工調整都建立 `InventoryMovement`。

## 庫存異動類型

```text
StockIn
Reserve
Release
Ship
ReturnToStock
ManualIncrease
ManualDecrease
Damage
Adjustment
```

人工調整必須填寫原因並寫入 Audit Log。
