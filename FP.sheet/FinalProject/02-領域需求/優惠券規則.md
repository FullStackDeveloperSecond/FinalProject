# 優惠券規則

狀態：已確認

## 第一版優惠券類型

### 固定金額折扣

例如滿 NT$3,000 折 NT$300，折扣不得使符合資格的商品金額低於零。

### 百分比折扣

例如滿 NT$20,000 打九折，必須設定最高折抵金額，避免高價電腦產生不可控折扣。

### 免運券

一般免運券適用一般宅配或超商取貨。組裝電腦宅配只有專用的組裝電腦免運券能折抵。

## 共通規則

| 規則 | 決策 |
|---|---|
| 每張訂單優惠券數量 | 一張 |
| 優惠券互相疊加 | 不允許 |
| 訪客使用 | 公開優惠碼可以 |
| 會員專屬券 | 必須登入 |
| 商品特價搭配優惠券 | 預設可以，但優惠券可設定排除 |
| 使用期間 | 必須設定開始與結束時間 |
| 最低消費 | 可設定 |
| 百分比最高折抵 | 必須設定 |
| 總使用次數 | 可設定 |
| 每人使用次數 | 可設定，預設一次 |
| 適用範圍 | 全站、指定分類、指定商品 |
| 排除商品 | 可設定 |
| 組裝費 | 不參與折扣 |
| 運費 | 只有免運券可折抵 |
| 訂單快照 | 必須保存 |

訪客每人使用限制以正規化後的訂購 Email 及完成訂單紀錄判斷，但文件需註明這無法完全防止使用者更換 Email。

## 計算順序

```text
1. 商品原價
2. 商品特價
3. 找出符合優惠券的商品
4. 套用固定金額或百分比優惠券
5. 加入組裝費
6. 判斷配送與滿額免運
7. 套用免運券
8. 產生訂單總額
```

- 同一 SKU 的有效特價期間不得重疊；建立或修改特價時需直接拒絕重疊區間。
- 特價後仍可套用符合條件的一張優惠券；原價、特價與優惠券折扣分開保存快照。

免運門檻使用優惠券折扣後的符合資格商品小計判斷，不包含運費、組裝費與贈品價格。

## 優惠券狀態

```text
Draft
Scheduled
Active
Paused
Expired
Exhausted
Disabled
```

使用時仍需重新檢查時間、總量、每人次數、會員資格及商品範圍，不能只依賴狀態欄位。

## 使用與併發

```text
開始資料庫交易
→ 驗證優惠券及狀態
→ 驗證總使用量與每人使用量
→ 驗證商品及最低消費
→ 後端計算折扣
→ 建立訂單
→ 建立 CouponRedemption
→ 提交交易
```

前端只能顯示預估折扣。只剩一個使用名額時，多位使用者同時結帳也只能成功一筆。

## 訂單快照與折扣分攤

日後修改優惠券不能影響既有訂單，因此需保存：

```text
OrderCouponSnapshot
├─ CouponCode
├─ CouponName
├─ CouponType
├─ OriginalRulesJson
└─ DiscountAmount
```

訂單層級折扣按符合資格商品的成交金額比例分攤至 `OrderItemDiscountAllocation`，以支援單項退貨與部分退款。

## 取消與返券

| 原因 | 返還使用次數 |
|---|:---:|
| 顧客在允許階段取消 | 是 |
| 付款失敗或逾時 | 是 |
| 缺貨或系統取消 | 是 |
| 商家取消 | 是 |
| 完成後退貨 | 否 |
| 違規或濫用 | 否 |

返還使用次數不延長優惠券期限；優惠券已到期時不恢復可用。
