## 依賴順序與 Gate

1. **GATE-TX-01｜契約凍結**：Cart、Coupon、Shipping 必須提供 Checkout 只讀 Query／DTO；Haru 擁有 Checkout Use Case 與交易邊界。不得由 Checkout 直接讀取其他模組底層表。
2. **GATE-TX-02｜SQL 原子交易**：建立 Order、OrderItems、Coupon／費用快照與 InventoryReservation 必須同交易成功或全部回滾；兩個請求競爭最後一件商品時只能一筆成功。
3. **GATE-TX-03｜付款一致性**：`Order.GrandTotal`、`PaymentAttempt.Amount` 與成功後 `PaidAmount` 必須一致；同 Idempotency-Key replay 不重複建單、扣庫存或付款。
4. **GATE-TX-04｜宅配限制**：既定訪客宅配路徑只能使用預付；費用、滿額免運與組裝配送限制由可信 Shipping／Coupon 規則計算並保存快照。
5. **GATE-TX-05｜Provider-backed 整合**：使用 CI connection template 建立專屬 SQL 測試庫，實際套用四支 Migration；涵蓋成功、缺貨、競爭、付款失敗／replay 與整體回滾。
6. **GATE-TX-06｜E2E**：Typed Client 更新後，瀏覽器從 Cart UI 完成既定訪客旅程，並以 API／SQL 斷言 Order、Reservation、Payment 與通知排程結果。
