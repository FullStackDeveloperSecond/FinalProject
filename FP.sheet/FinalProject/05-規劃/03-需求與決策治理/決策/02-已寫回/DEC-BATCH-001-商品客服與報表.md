# DEC-BATCH-001｜商品、客服與報表第一批決策

本批次已寫回正式需求、架構、狀態機、權限、名詞表及追蹤表。

## 決策

| ID | 最終決策 | 尚未解決的部分 |
|---|---|---|
| DEC-P01 | 商品批次上下架、批次調價、Excel 匯入及匯出全部列為 M | 匯入欄位契約、驗證、錯誤回報、部分成功與回滾規則 |
| DEC-P02 | 所有商品規格欄位都可由管理員動態新增、修改及刪除 | 必須解決相容性程式依賴固定欄位時的識別、刪除、改名與型別變更規則 |
| DEC-P03 | 相容性規則程式由開發者維護；管理員可查看規則、啟停設定值及執行測試 | 與 DEC-P02 的動態規格欄位生命週期需先取得一致設計 |
| DEC-P04 | 客服案件、檢舉及退貨為三個獨立領域資料；管理後台以統一工作台彙整顯示 | 統一查詢契約、分頁排序、跨領域權限與附件關聯方式 |
| DEC-P05 | 客服案件分類採訂單、付款、物流、商品與保固、退貨協助、帳號、其他七類 | 無 |
| DEC-P06 | 客服案件採完整狀態集合；重開是狀態轉移事件，不是獨立狀態 | 自動結案天數、Closed 後能否重開、各轉移角色與副作用 |
| DEC-P07 | 未指派客服案件進共用佇列；客服可自領，主管可指派及轉派 | 主管對應角色，以及此佇列是否涵蓋檢舉與退貨 |
| DEC-P08 | 第一版實作完整客服 SLA | 優先級、首次回覆與結案期限、營業時間、暫停、重開、逾時通知及升級規則 |
| DEC-P09 | 客服附件使用本機私有目錄及授權下載 API；支援 PNG、JPG、PDF；每案最多 3 個且單檔 10 MB | 惡意檔案檢查、保存期限、刪除排程、孤兒檔清理，以及是否套用檢舉與退貨 |
| DEC-P10 | 銷售總覽、商品排行與 ABC 分級、同期比較、庫存周轉、毛利、關聯組合、預測與異常偵測七個畫面全部列為 M | 成本快照、指標公式、資料口徑、最低樣本數、資料不足與異常處理、匯出格式及效能門檻 |

## 套用約束

1. DEC-P02 與 DEC-P03 的衝突保留於追蹤表，不在本批次中擅自補決策。
2. 統一案件工作台不代表客服、檢舉及退貨共用案件主表。
3. 客服七類只適用一般客服案件。
4. 完整 SLA 雖列為 M，但未自行填入時數或營業日規則。
5. 七個報表列為 M 不會把 AI 報表分析從 S 升為 M，也不會把自然語言營運查詢移出 O。
