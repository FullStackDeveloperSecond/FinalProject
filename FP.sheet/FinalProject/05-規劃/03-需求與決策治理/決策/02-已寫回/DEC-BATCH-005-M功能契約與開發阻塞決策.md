## 一致性與保留事項

- DEC-P101 與 DEC-P102 可共同成立：系統同時支援 XLSX／CSV，且資料內容分成 Product、SKU、Specification 三個邏輯資料集。
- 尚未決定 CSV 要使用三個獨立檔案、ZIP 封裝或三個獨立上傳入口；正式文件只固定邏輯資料集與原子驗證，不替團隊選擇包裝方式。
- DEC-P97 固定採 Provider Profile 安全範圍，但各欄位實際上下限仍需另行決定。
- DEC-P110 固定 Schema 邊界，但完整 JSON Schema 的欄位型別、Enum 與版本內容仍需詳細設計。
