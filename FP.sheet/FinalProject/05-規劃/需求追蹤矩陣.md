## 狀態定義

| 標記 | 意義 |
|---|---|
| ✅ | 已有可直接引用的正式內容 |
| 🟡 | 已有部分內容，尚不能作為完整開發契約 |
| ⬜ | 尚未建立或尚未選定 |

## 目前阻塞點

1. 37 個 M 使用案例已建立，但待決欄位與 Endpoint／資料表精確回連尚未全部定版，對應 `REQ-02`、`REQ-03`。
2. 邏輯 ERD、資料字典索引與 Endpoint 草案已建立；完整欄位、DTO、索引、Policy 與 OpenAPI Schema 仍未完成，對應 `DES-07`、`DES-08`、`DES-10`。
3. 五條核心 E2E 已固定，37 個案例也已有測試層級；仍缺逐案自動化細目、負責人與覆蓋率決策，對應 `QA-03`。
4. 第六批決策將處理模型、Schema Enum、CSV、物流界限、相容性門檻、工具與品質門檻等主要阻塞。

## 更新規則

- 正式文件新增或狀態變更時，同一批修改必須同步更新本表。
- Endpoint 目錄與資料字典建立後，以穩定 ID 連結，不在本表複製完整欄位。
- 功能降級、移出第一版或改變 M/S/O 時，必須先更新 [[01-需求/功能範圍]] 與決策紀錄。
