# 三十項決策互動模板

> [!warning]
> 複製本檔後再填入實際問題、選項與建議。不要直接在模板上作答。

目前狀態：`VIEW[{status}]`

## 每題格式

### DEC-XXX｜決策標題

說明決策背景、影響與邊界。

> [!tip] 建議
> 建議方案及理由。

**方案選擇**

```meta-bind
INPUT[select(
  option(recommended, '方案 A（建議）'),
  option(alternative_b, '方案 B'),
  option(alternative_c, '方案 C'),
  option(custom_only, '完全採自主方案')
):q01_choice]
```

**自主輸入（可補充或取代選項）**

```meta-bind
INPUT[textArea(placeholder('輸入補充內容或完整自主方案')):q01_custom]
```

實際批次依相同格式建立 30 題，分別綁定 `q01` 至 `q30`。

## 批次操作

`BUTTON[submit-decision-batch,restore-draft]`

```meta-bind-button
label: 送出本批 30 項決策
style: primary
id: submit-decision-batch
hidden: true
actions:
  - type: updateMetadata
    bindTarget: status
    evaluate: false
    value: submitted
```

```meta-bind-button
label: 退回草稿
style: default
id: restore-draft
hidden: true
actions:
  - type: updateMetadata
    bindTarget: status
    evaluate: false
    value: drafting
```
