# 2026-08-21 16:34 PR #10 CI 修正日誌

## 問題原因

- Admin Web CI 以零 warning 為必要條件；`queries.spec.ts` 在同一檔案宣告多個 Vue Harness，產生兩個 lint warning。
- Backend CI 使用 Ubuntu，但原流程未啟動 SQL Server，也未覆寫 Windows named instance `Server=.\\SQL2025`，造成 31 項 SQL 整合測試無法連線。

## 修正內容

- Admin query 測試改為共用單一 Harness，不關閉 lint 規則。
- Backend CI 新增 SQL Server 2022 service、TCP 測試連線字串與健康檢查。
- CI 在執行測試前還原本機 EF Tool 並套用現有 Migration。
- 首次推送後確認 SQL container、Restore、Build、Format 均成功；Migration 因誤用 `DoSelect.Api` 作 startup project 而失敗。
- 依組長工程包改用 `DoSelect.Infrastructure` 作 project 與 startup project，並明確指定 `InitialCreate`／`DoSelectDbContext`。
- Migration 修正後 CI 已進入完整測試；系統環境重跑確認 132 項只剩 M14B SLA 測試受第一頁 100 筆限制影響。
- SLA SQL 驗收改用正式 keyset cursor 逐頁讀取，避免共用或平行測試資料將本次 fixture 擠出第一頁；保留 terminal 排除與精確欄位斷言。
