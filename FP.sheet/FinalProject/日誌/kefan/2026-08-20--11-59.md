## 定義與對外契約

### 正確取用方式

| 項目 | 定義 |
|---|---|
| `SupportTicket.Handle` | `CustomerService` 或 `CustomerServiceSupervisor`；SuperAdmin 單一角色不通過 |
| `SupportTicket.Supervise` | `CustomerServiceSupervisor` 或 `SuperAdmin` |
| claim | `POST /api/v1/admin/support-tickets/{id}/actions/claim`，Handle |
| SLA | `GET /api/v1/admin/support-tickets/sla`，Handle |
| 工作台 | `GET /api/v1/admin/case-workbench`，本階段 Handle 且最大範圍為 Support |
| assignment conflict | HTTP 409、`support_ticket_assignment_conflict`、標準 Problem Details |

### 必須維持的規則

- 多角色採權限聯集，但 `SuperAdmin` 不自動取得 Handle。
- Policy 不可繞過案件狀態、Actor/承辦範圍、RowVersion、必填理由、歷程與 Audit。
- 409 僅使用共同 `code`、`traceId`、`correlationId` 管線，不加入承辦人擴充欄位。
- acting admin 一律從已驗證的 `NameIdentifier` claim 取得，不接受 request body 指定。
- Report/Return 工作台角色映射尚未確認，不得藉由本 Endpoint 擴張。
