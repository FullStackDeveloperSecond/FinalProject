## 更改內容

### 摘要

依組長定版，全案採單一 `DoSelectDbContext` 對應單一 `DoSelectDb` 及 Migration 歷程；Entity 與 Fluent Configuration 依模組分資料夾。EF Core、Identity EF Store、Design Package 與 Repository-local dotnet-ef 均固定 `10.0.10`。

### 新增

- `DoSelectDbContext`，繼承 Identity DbContext 並掃描 Infrastructure Assembly 的所有 Configuration。
- `ApplicationUser` Identity Store 基礎型別。
- `AddDoSelectPersistence` DI 與 `DefaultConnection` 必填邊界。
- `DoSelectDbContextFactory`，供不啟動 API／不讀取其他 Secret 的設計期工具使用。
- `.config/dotnet-tools.json`，固定 `dotnet-ef 10.0.10`。
- 3 個持久化基礎測試。

## 定義與對外契約

| 項目 | 定義 |
|---|---|
| DbContext | `DoSelect.Infrastructure.Persistence.DoSelectDbContext` |
| Database | `DoSelectDb` |
| Provider | EF Core SQL Server `10.0.10` |
| Identity Store | `Microsoft.AspNetCore.Identity.EntityFrameworkCore 10.0.10` |
| Migration Assembly | `DoSelect.Infrastructure` |
| Connection Key | `ConnectionStrings:DefaultConnection` |
| 模組隔離 | Domain Entity／Infrastructure Configuration 依模組資料夾；單一 Context 統一套用 |

### 必須維持的規則

- 不建立每模組獨立商業 DbContext 或 Migration。
- 跨模組寫入由 Application Use Case 協調同一 Unit of Work。
- 跨模組查詢仍透過公開 Query／DTO，不直接使用其他模組 Repository。
- API 啟動不得自動執行 `Database.Migrate()`／`MigrateAsync()`。
- Migration 必須經獨立安全審查後才能套用。
