## 更改內容

- `ReturnRequests` 新增 Low／Normal／High／Urgent Priority，建立預設 Normal，具名方法可調整並更新 UpdatedAtUtc。
- 新增工作台查詢索引 `Status + Priority + AssigneeAdminUserId + UpdatedAtUtc`。
- 建立 `20260819013357_InitialCreate`、Designer 與 `DoSelectDbContextModelSnapshot`。
- 初始 Migration 建立 93 張應用／Identity 表、315 個索引與 `vw_CaseWorkbench`。
- View 使用三個 `UNION ALL` 分支；Title 採 Category／ReasonCode，RequesterDisplay 只回會員／訪客。
- Support SLA 依首回／結案階段切換，WaitingForCustomer 暫停累計上限 72 小時；終態與 Return／Report 不標示 SLA 逾期。
- SQL Server `CREATE VIEW` 以 `EXEC(N'...')` 建立獨立動態批次；Down 先 Drop View 再 Drop 來源表。
