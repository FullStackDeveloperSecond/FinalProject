## 更改內容

- 直接驗證 SQL Server `\.\SQL2025` 服務與 Windows Authentication。
- 分別驗證 API `/health/live` 與 `/health/ready` 的 HTTP 狀態及安全 JSON `status`。
- 直接驗證消費者前台與管理後台 HTTP 回應，不以 PID 存在取代健康狀態。
- 每項輸出狀態、Latency、Target 與不含 Secret 的摘要。
- 必要檢查失敗回傳 Exit Code 1；Readiness Degraded 依既有降級契約警告並保留 Exit Code 0。

## 定義內容與組員取用方式

在 `FP.dev` 且服務已啟動時執行：

```powershell
.\scripts\health-check.ps1
```

需要調整單次 HTTP Timeout 時可使用 `-TimeoutSeconds 1..30`。腳本適合人工執行或由其他 PowerShell／CI 流程依 Exit Code 判斷，不會輸出連線字串、路徑或遠端例外內容。
