## 更改內容

- 固定 API `5126`、消費者前台 `5173`、管理後台 `5174`，占用時直接失敗。
- 預設 `Development`，以 `-Environment Demo` 明確切換展示環境。
- 啟動前驗證必要命令、SQL Server `\.\SQL2025` 服務、Windows Authentication 連線及固定 Port。
- API 必須通過 `/health/ready`，兩個 Vue 站台必須回應成功才宣告完成。
- `.run/processes.json` 保存受管 PID 與 UTC 啟動時間；停止前重新核對，避免 PID 重用或誤停其他專案。
- stdout／stderr 寫入 `.run/` 並由 Git 忽略。

## 定義內容與組員取用方式

在 `FP.dev` 執行：

```powershell
.\scripts\start-all.ps1
.\scripts\status.ps1
.\scripts\stop-all.ps1
```

展示環境使用：

```powershell
.\scripts\start-all.ps1 -Environment Demo
```

不得直接編輯 `.run/processes.json`，也不得以終止所有 Node／.NET 程序取代 `stop-all.ps1`。若 Port 被占用，先依腳本顯示的 PID 確認來源，再處理該程序。
