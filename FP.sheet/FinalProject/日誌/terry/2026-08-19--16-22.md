## 更改內容

### 摘要

補齊 M-03／M-05 第一個切片「讀取與一般搜尋，再完成管理 CRUD」中，目前不受身分驗證缺口阻擋的所有部分：三個公開讀取 API、五個資源的管理 CRUD 業務邏輯（尚未對外開放）、對應的兩個前台頁面，並讓整條路徑（資料庫→API→前端）在瀏覽器中實際跑通。管理 CRUD 的 Controller 因缺少 alex 的 SH-05 身分驗證基礎而刻意不建立對外路由，避免上線未受保護的管理端點。

### 新增

**公開讀取 API**（`DoSelect.Application/Catalog`、`DoSelect.Infrastructure/Catalog`、`DoSelect.Api/Catalog`）
- `GET /api/v1/products`（UC-SEARCH-01）：關鍵字、分類、品牌、價格區間、庫存、動態規格（`eq/gte/lte/in`）篩選；`relevance/priceAsc/priceDesc/newest` 排序，固定加上上架時間＋SKU Code 的穩定分頁排序；有效特價自動覆蓋原價。
- `GET /api/v1/products/{id}`：商品明細，含全部已上架 SKU、規格比較表（`specificationGroups`）、標籤；只回已發布商品，404 不揭露資源是否存在。
- `GET /api/v1/catalog/filter-options`：分類／品牌／價格區間／規格篩選器選項；品牌只回有上架商品者，規格篩選器只在指定 `category` 時回傳。
- `ProductSearchQueryValidator`、`CatalogSearchException`：`sort`／規格運算子驗證獨立於一般 Model Validation，對應契約的 `search_sort_unsupported`／`search_filter_unsupported` 專屬錯誤碼。

**管理 CRUD 服務層**（僅 Application＋Infrastructure，未接 Controller）
- `IBrandAdminService`／`ICategoryAdminService`／`ITagAdminService`：新增、修改、分頁查詢；Category 驗證父分類存在且拒絕以自己作為父分類。
- `IProductAdminService`：新增、修改、單筆查詢、依品牌／分類／狀態篩選的分頁查詢，標籤關聯整批替換。
- `ISkuAdminService`：新增、修改、單筆查詢、刪除；同商品最多一個預設 SKU（設新預設會自動取消舊預設）、規格值依商品分類的規格定義驗證型別、只允許刪除從未被引用的草稿 SKU。
- 全部寫入操作使用 `RowVersion` 樂觀併發，錯誤碼對齊 `03-架構/API錯誤碼目錄.md`（`product_code_duplicate`、`sku_code_duplicate`、`concurrency_conflict`、`specification_invalid` 等）。

**customer-web 前台頁面**
- `/products`（C-02）：關鍵字／分類／品牌／現貨／排序篩選，條件與頁碼寫入 URL Query（可分享、可返回同步）；載入中／空白／錯誤／分頁狀態齊全。
- `/products/:productId`（C-03）：商品資訊、多 SKU 切換、規格表、標籤；「加入購物車」按鈕固定停用並附說明，因購物車 API（M-06）尚未存在，不假裝可用。
- `src/api/generated/schema.d.ts`：以 `openapi-typescript` 從執行中的 API 即時產生，新增 `npm run generate:api` 腳本；未手寫任何 DTO。
- Vite Dev Server 加上 `/api` 同源代理（`vite.config.ts`），避免為了本機預覽去動後端 CORS 設定（那是共用範疇）。

### 正確取用方式

| 項目 | 定義 |
|---|---|
| 前端 API 路由與 HTTP Method | `GET /api/v1/products`、`GET /api/v1/products/{id}`、`GET /api/v1/catalog/filter-options` |
| Request DTO | `ProductSearchRequest`、`SpecFilterRequest`（`DoSelect.Api.Catalog`） |
| Response DTO | `PageResult<ProductCardDto>`、`ProductDetailDto`、`CatalogFilterOptionsDto`（`DoSelect.Application.Catalog`） |
| 後端介面／Application Service | `IProductSearchService`、`IProductDetailService`、`ICatalogFilterOptionsService` |
| 領域事件／整合事件 | 無 |
| 必要權限或 Policy | 讀取 API：Public；管理 CRUD 服務層：預期 `CatalogManager`／`SuperAdmin`，但目前無對外路由可驗證 |
| 成功條件 | 200 回傳對應 DTO；管理服務層以回傳值／拋出 `CatalogWriteException` 表示成功或失敗 |
| 可能錯誤碼 | `search_sort_unsupported`、`search_filter_unsupported`、`resource_not_found`；管理層：`product_code_duplicate`、`sku_code_duplicate`、`sku_code_immutable`、`sku_delete_referenced`、`specification_invalid`、`concurrency_conflict`、`brand_code_duplicate`、`category_code_duplicate`、`tag_code_duplicate`、`category_parent_invalid`（新定義，非既有錯誤碼目錄項目）、`reference_not_found`（新定義） |

### 命名與型別

| 名稱 | 型別／格式 | 是否可為空 | 說明／範例 |
|---|---|---|---|
| `ProductAvailabilityCodes` | `string` 常數（非 C# enum） | 否 | `inStock`／`lowStock`／`outOfStock`；因專案尚未定案 Enum 的 JSON 命名規則，故以字串常數避免序列化格式不一致 |
| `ProductSortOptions` | `string` 常數 | 否 | `relevance`／`priceAsc`／`priceDesc`／`newest` |
| `category_parent_invalid`、`reference_not_found` | 錯誤碼字串 | 否 | 本次新增，`03-架構/API錯誤碼目錄.md` 未列出，需與 alex／kafen 對齊是否納入正式目錄 |

### 必須維持的規則

- 商品／SKU 只顯示已上架且狀態為 Published 者於公開 API；管理 API 不受此限制。
- 特價計算固定用「目前生效特價 ?? 原價」，訂單／購物車不得回查 `SalePrices`。
- 每個商品最多一個預設 SKU；管理層設定新預設時必須同交易取消舊預設。
- 規格值寫入前必須驗證對應商品分類存在該規格定義且型別相符。
- SKU 刪除僅限「狀態為 Draft 且未被庫存／保留／異動／購物車／組裝清單引用」。

### 禁止或不建議的取用方式

- 不可由前端直接存取資料庫。
- 不可跨模組直接操作其他模組的 Repository 或資料表。
- 不可對外暴露資料庫內部 `bigint Id`；對外識別使用 `PublicId`。
- 管理 CRUD 服務層目前**不得**被任何 Controller 呼叫並公開為 HTTP 端點，直到 SH-05 身分驗證／授權基礎存在為止；提前公開等同繞過共用授權能力，工程包已明確禁止。
