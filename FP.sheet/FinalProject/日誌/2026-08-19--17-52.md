# 開發日誌｜DEC-BATCH-014 優惠券、退款與模擬發票契約定版

## 作者與負責範圍

| 欄位 | 內容 |
|---|---|
| 作者 | alex／Codex |
| 本次範圍 | 將 yinyin 提出的十項優惠券、付款、退款與模擬發票問題依組長採納建議正式定版，寫回規格、狀態機、API、Schema、測試與追蹤文件 |
| 不在本次範圍 | 修改 Domain／Application／Infrastructure 程式、建立或套用 EF Core Migration、開 PR 或合併功能分支 |
| 後續負責 | yinyin 主責優惠券／付款／退款／模擬發票；haru 配合 OrderItem 快照；alex 執行契約與 Migration Review |

## 定版內容

- 優惠券最低消費只比對適用商品小計。
- Coupon 完整狀態機；Exhausted 可在合法名額返還後恢復，Expired／Disabled 為終態。
- Cart 不持久化優惠碼，Checkout 一律重新驗證。
- CouponRuleReader 以 SQL Server Provider-backed 整合測試驗證，不新增 InMemory／SQLite 替代。
- 付款嘗試期限取付款方式窗口與訂單原期限較早者。
- OrderCoupon 保存 `MinimumSpendAmount`；OrderItem 保存 `IsCouponEligible`。
- RefundAllocation Amount 保持正值，由類型固定表達增加退款或扣回，新增 `ShippingClawback`。
- 模擬發票補齊前台查詢、後台查詢／開立／作廢／折讓 Endpoint、具名 DTO 與五個 409 錯誤碼。
- 模擬發票／折讓固定 5% 稅率與 TWD 整數元，採 `AwayFromZero` 與最後明細尾差；1,000 固定為 952＋48。

## 定義與交接

| 契約 | 定義 | 取用者 |
|---|---|---|
| 優惠門檻基準 | 適用商品小計，不含其他商品、組裝費與運費 | CouponCalculator、Checkout、Refund Calculator |
| 退款快照 | `MinimumSpendAmount`＋`IsCouponEligible`＋原始成交／折扣分攤 | yinyin／haru／kafen |
| Allocation 方向 | `Amount > 0`；增加型合計減扣回型合計 | Refund 寫入層、後台退款明細、報表 |
| 付款期限 | `Min(付款方式期限, Order.PaymentDueAtUtc)` | PaymentAttempt 建立與逾時工作 |
| 發票 API | Owner／Guest Scope 查詢；FinanceManager／SuperAdmin 執行開立、作廢、折讓 | Yinyin API／Application／前端 Typed Client |
| 發票稅額 | `Net=Round(Gross/1.05,0,AwayFromZero)`；`Tax=Gross-Net`；最後一筆吸收尾差 | InvoiceCalculator、AllowanceCalculator、測試與匯出 |
