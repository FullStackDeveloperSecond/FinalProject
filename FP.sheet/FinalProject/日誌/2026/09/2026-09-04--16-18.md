- Live Adapter 沒有執行的案例必須顯示 `NOT_RUN_BY_LIVE_ADAPTER`，不可算作通過。
- deterministic 全通過但人工 required points 尚未覆核時，結果只能是 `PENDING_HUMAN_REVIEW`。
- 新版 Release dry run 固定為 36 selected、22 live、14 deterministic／orchestration、三輪 96 規劃請求。
- 批次中斷不得遺失已完成案例；`checkpoint.json` 不保存 API Key 或原始 Request Payload。
