## 更改內容

### 摘要

建立前後台 Cookie 認證的共用安全管線，讓商業模組可使用固定 Policy，不必自行建立平行認證邏輯。瀏覽器 unsafe method 現在會全域驗證 Anti-forgery Token，前後台各自明確選擇 Cookie Scheme。

### 新增

- `DoSelect.Api/Security`：Scheme、Claim、Role、Policy 常數，Cookie／CORS／Anti-forgery 設定，全域 Filter 與 Token Endpoint。
- `frontend/shared/src/api/antiforgery.ts`：只存記憶體、合併並行取得、Session 改變可重設的 Token Provider。
- Security 整合測試：Token、Cookie 隔離、MFA、客服 Policy、CORS 與已登入 unsafe request。

### 修改

- API Pipeline 加入 CORS、Authentication、Authorization 與全域 Anti-forgery。
- customer-web／admin-web 分別固定使用 `member`／`admin` Client Header。
- 正式 API 規範、Endpoint／錯誤碼目錄、決策紀錄與追蹤表同步實作契約。

### 刪除或淘汰

- 無；未增加完整 ASP.NET Core Identity 套件或第二套認證管線。

## 定義與對外契約

### 提供給其他模組的能力或資料

| 能力／資料 | 提供者 | 使用者 | 用途 |
|---|---|---|---|
| `DoSelectAuthenticationSchemes.Member／Admin` | DoSelect.Api | 登入與 Session 模組 | 發行或驗證正確 Cookie |
| `DoSelectPolicies.*` | DoSelect.Api | 各管理與會員 Controller | 套用角色、MFA 與 Scheme Gate |
| `GET /api/v1/security/antiforgery-token` | DoSelect.Api | customer-web／admin-web | 取得 unsafe request 使用的 Request Token |
| `resetAntiforgeryToken()` | 各 Vue API client | 登入／登出流程 | Session 改變後清除記憶體 Token |

### 正確取用方式

| 項目 | 定義 |
|---|---|
| 前端 API 路由與 HTTP Method | `GET /api/v1/security/antiforgery-token` |
| Request DTO | 無 Body；Header 必須是 `X-DoSelect-Client: member` 或 `admin` |
| Response DTO | `AntiforgeryTokenResponse{requestToken}`；禁止快取 |
| 後端介面／Application Service | Controller 以 `[Authorize(Policy = DoSelectPolicies.X)]` 使用，不在 Action 內自行比對角色字串 |
| 領域事件／整合事件 | 無 |
| 必要權限或 Policy | `Member`、`Admin`、九個高風險 Policy、`SupportTicket.Handle／Supervise` 及 `CatalogManager` |
| 成功條件 | unsafe request 同時攜帶對應 Cookie 與 `X-XSRF-TOKEN` |
| 可能錯誤碼 | `validation_failed`、`antiforgery_validation_failed`、`authentication_required`、`authorization_forbidden` |

### 必須維持的規則

- 會員 Cookie：閒置 8 小時滑動、最長 7 天；管理員 Cookie：2 小時、不滑動。
- 正式環境 Cookie 必須 Secure、HttpOnly、SameSite=Lax；CORS 只允許設定的明確 Origin 並允許 Credentials。
- 管理 Policy 必須同時滿足 Admin Scheme、Admin Account Type 與 `amr=mfa`。
- `SuperAdmin` 單一角色不可通過 `SupportTicket.Handle`，但可通過 `SupportTicket.Supervise`。
- Token 只存記憶體；登入、登出或身分切換後必須呼叫 `resetAntiforgeryToken()`。
