## 更改內容

- 新增目前 AI 同意查詢、Grant／Withdraw append-only 流程與會員本人用量查詢。
- AI 客服 Request 可引用本人 Order、SupportTicket 公開訊息與既有 Conversation；Owner 驗證發生在額度預留及 OpenAI 呼叫前，排除 Internal Note、附件、Sender 身分與個資。
- 新增 `AiConversations`、`AiInteractions`、`AiCitations` Entity／Configuration／Migration；保存模型、Prompt／Schema Version、實際 Input／Output Token、估算成本、狀態、延遲與可信引用。
- 前台新增伺服器同意狀態、揭露／撤回、用量、聊天、引用、免責提示與人工客服降級；後台新增 A-28 AI 用量與成本保護頁。
- A-28 固定允許 SuperAdmin、FinanceManager、CustomerServiceSupervisor、MarketingAnalyst；成本金額只回 Finance／SuperAdmin。
- 新增 `OpenAI:BudgetAlertRecipientAdminPublicId`。AI 啟用時必須是非空 `AspNetUsers.PublicId`；執行時確認 Active Admin、有效 AdminProfile 與 SuperAdmin。首次跨越 US$70 時，Interaction 與 Email／站內通知 Outbox 在同一 Serializable 交易保存，之後不重複通知。
- US$90 停用非 Demo AI 流量；最多兩個 Demo Member PublicId 只繞過此成本停止門檻。
- Responses strict Schema 補入 `support_ticket` 引用型別，與後端核准來源白名單一致。
- 寫回 DEC-BATCH-034／DEC-P335～P339、角色矩陣、AI 驗收、設定、詳細設計、M 矩陣與未完成追蹤。

## 定義與交接契約

| 取用者 | 契約 |
|---|---|
| 前台 | 只傳公開資源 PublicId；不得傳原始訂單、客服歷史、個資或 Internal Note。未同意、額度不足、AI 停用、成本保護或服務失敗都提供人工客服入口 |
| Support／Order | Context Reader 只讀當前登入會員本人投影；SupportTicket 最多 3 筆且只取公開訊息，不送附件或人員識別 |
| 維運 | `OpenAI:BudgetAlertRecipientAdminPublicId` 使用 `AspNetUsers.PublicId`。Development Seed 組長為 `0f269121-89a5-43a4-97f5-b95278bc0cf6`；換帳號或撤銷 SuperAdmin 前必須先更新設定 |
| 通知 | `ai.budget.warning` 使用既有 Outbox／Email／站內通知；不得在 HTTP Request 內直接寄信。門檻事件以低於 70 到大於等於 70 的首次跨越判斷 |
| M-18 | 後續商品搜尋成本亦保存到 `AiInteractions`；若 M-18 可能成為首次跨越 US$70 的寫入路徑，必須重用相同通知契約，不得建立第二套收件或門檻規則 |
| 資料庫 | Migration 只新增三張表、Restrict FK、Check Constraint 與索引；不得以 `EnsureCreated` 取代 Migration，也不得由應用程式啟動時自動套用 |

## Migration 風險與回復

- `Up()` 為加法式變更，不 Alter／Drop／Update／Delete 既有表或資料，風險評級 Low；新表初始為空，不需 Backfill。
- `Down()` 會刪除三張 AI 表及部署後的新資料，因此只具結構回復能力，不是資料回復方案。正式套用後優先關閉 `Features:AiEnabled` 並以修正 Migration Roll Forward。
- 本次只 Scaffold、產生 SQL 與靜態審查；未執行 `database update`，未套用共用或正式資料庫。
