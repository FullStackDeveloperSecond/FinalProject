## 更改內容

- 建立商品、SKU、標籤、多語翻譯、圖片、規格來源與特價等型錄資料模型。
- 建立 Import Batch／Row、會員與訪客購物車、庫存餘額／保留／異動／核對案件。
- 建立物流方式、供應商版本、包裹限制、超商門市、出貨及 append-only 狀態歷程。
- 建立組裝清單、分享 Token、相容性設定／執行／結果與商品評價版本模型。
- 補齊 Favorite→Product、OrderItem→SKU、Order→ShippingProviderProfile 等 Haru 跨模組 Restrict FK。
- 依 Cascade 白名單只允許 ImportRows、CartItems、BuildListItems 隨父資料刪除。
- 相容性 Overall 依較高權威契約固定為 `Compatible/Warning/Blocked/InsufficientData`。
- 組長確認修正 `BuildListItems.PublicId` 誤植索引：正式名稱為 `UX_BuildListItems_PublicId`。

## 定義與對外契約

| 項目 | 定義 |
|---|---|
| Entity 封裝 | 公開 getter／private setter；變更透過建構、Factory 或具名方法 |
| 可售庫存 | `AvailableQuantity` 為 SQL Server persisted computed column：OnHand－Reserved |
| 庫存稽核 | InventoryMovement 為 append-only；Before＋Delta 必須等於 After |
| 翻譯 | Locale 固定 `zh-TW/ja-JP/ko-KR`；AI 草稿與人工審核狀態分離 |
| Guest Secret | Cart／Build Share 僅保存 binary(32) Hash |
| 評價 | 一個 OrderItem 最多一筆有效評價；公開內容變更前保存 Revision |
