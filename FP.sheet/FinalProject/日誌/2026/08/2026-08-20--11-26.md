### 命名與型別

| 名稱 | 型別／格式 | 是否可為空 | 說明／範例 |
|---|---|---|---|
| `TicketPublicId`／`CasePublicId` | UUID | 否 | 對外識別，不暴露 bigint Id |
| `Assignee` | `AdminAssigneeSummaryDto` | 是 | 僅 `PublicId`、`DisplayName`，不回 Email／Identity Id |
| `UsageRatio` | double | 否 | 已使用有效秒數 ÷ 該階段目標秒數，可大於 1 |
| `EffectiveDueAtUtc` | UTC datetime | 否（SLA） | 首回前使用首回期限；首回後使用結案期限加最多 72 小時暫停 |
| `NextCursor` | opaque string | 是 | 無下一頁時為 null；不可自行拆解或跨查詢重用 |

### 必須維持的規則

- `Resolved`、`Closed`、`Cancelled` 不進入 active SLA 佇列。
- `WaitingForCustomer` 暫停最多 259,200 秒；`WaitingForInternal` 不暫停。
- SLA 依 `IsOverdue DESC, EffectiveDueAtUtc ASC, TicketPublicId ASC` 穩定排序。
- 工作台依 `LastActivityAtUtc DESC, CasePublicId DESC` 穩定排序，Cursor 綁定 filters 與 authorized case-type scope。
- 工作台 V1 僅可回正式固定 12 欄。

### 禁止或不建議的取用方式

- 不可直接將 store 暴露給 Controller；應經 Application service 驗證 Query／Cursor。
- 不可把 Email、Identity string Id 或 bigint Id 加進公開 DTO。
- 不可使用 Offset／PageNumber 取代這兩個快速變動清單的 Cursor。
- 不可在前端自行重算 SLA 或授權範圍。
