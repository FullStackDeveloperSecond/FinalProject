## 更改內容

- 建立 `DoSelect.Application.Ai`：客服登入／Member Scope／同意／每日額度前置閘門。
- 建立本人訂單與客服歷史的 Owner 驗證及最小化投影；輸出不包含 Owner ID、姓名、Email、電話或地址。
- 外送 Prompt Envelope 強制經 Token、Secret 與常見個資樣式檢查；被拒內容不出現在 Result 或錯誤訊息。
- 固定四個只讀 Application 工具，沒有取消、退貨、退款、任意 SQL 或資料庫工具；訂單工具只使用可信登入 Member ID。
- 分離固定 System Instructions、Untrusted User Input 與 Untrusted Data，商品文字無法增加工具能力。
- 建立 SearchIntent Semantic Key／Operator／預算安全驗證，以及搜尋與客服的單次重試及安全降級決策。
- 將 SDK 精確基準升級為 `10.0.303`，仍使用 `rollForward: disable` 且禁止 Preview；建立 AUTO-DEC-010 並同步現行環境文件與工程包。

## 定義與跨模組取用

| 取用者 | 必須使用的能力 | 規則 |
|---|---|---|
| M-19 AI 客服 Controller／Adapter | `AiSupportRequestGate`、`AiPromptEnvelopeFactory.TryCreateSupport` | 只有 `MayCallModel=true` 且 Envelope 非 Null 時才可呼叫外部模型 |
| 訂單／客服 Query Adapter | `AiOrderSummaryProjector`、`AiSupportHistoryProjector` | `trustedMemberId` 只能來自伺服器登入內容；Forbidden／UnsafeContent 不得建立外送 Payload |
| OpenAI Tool Adapter | `AiToolCatalog`、`AiOrderToolRequestFactory` | 模型或前端提供的 Member ID 不得成為授權依據；只能暴露四個只讀工具 |
| M-18 AI 搜尋 | `AiSearchIntentSafetyValidator`、`AiFailurePolicy` | 驗證失敗不得查商品；逾時等暫時錯誤最多重試一次後降級關鍵字搜尋 |
