## 更改內容

- 建立 `Entity`、`PublicEntity`、`MutablePublicEntity` 共用基底，統一 bigint Id、PublicId、UTC 時間與 RowVersion。
- 正式 Entity 採公開 getter／private setter，透過 Constructor／Factory 與具名方法維持狀態不變量。
- 擴充 `ApplicationUser`，加入 PublicId、帳號類型／狀態、語系、匿名化時間與 RowVersion。
- 建立 MemberProfile、AdminProfile、MemberAddress、Favorite。
- 建立 Order、OrderItem、OrderStatusHistory、GuestOrderAccessRequest、GuestOrderAccessToken、AssemblyJob、AssemblyJobStatusHistory。
- 完成對應 Fluent Configuration、索引、Check Constraint、Restrict FK、精度、長度、Hash binary(32) 與 RowVersion。
- `DoSelectDbContext` 掛載 Haru 範圍 DbSet，仍維持單一 DbContext／Migration 歷程。

## 定義與對外契約

| 項目 | 定義 |
|---|---|
| 封裝規則 | 公開 getter／private setter；建立及修改只經建構、Factory 或具名商業方法 |
| 狀態歷程 | Order／Assembly 狀態歷程為 append-only Entity，Application Use Case 後續須與狀態更新同交易寫入 |
| Guest Secret | 驗證碼與 Token 僅保存 32-byte Hash，不保存明文 |
| Delete Behavior | Haru 所有正式 FK 採 Restrict |
| 跨模組邊界 | Favorite→Product、OrderItem→SKU 等待 Terry 實體形成後再建立正式 FK |
