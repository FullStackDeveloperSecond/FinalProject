## 更改內容

- Customer Web 與 Admin Web 的 `package.json` 使用精確 `vue-demi@0.14.10` `allowScripts` 核准。
- Repository 根 `.npmrc` 新增 `strict-allow-scripts=true`，讓未核准安裝腳本 Fail Closed。
- Package 來源驗證器要求嚴格設定存在且唯一，禁止 `dangerously-allow-all-scripts=true`，並要求每個核准鍵為精確 `package@version` 且值為 `true`。
- 自我測試新增關閉嚴格模式及非版本化核准兩條拒絕路徑。
- `glob@10.5.0` 目前只存在於開發測試相依鏈，依 DEC-P303 保留並設定重評條件，不使用跨主要版本 Override。
- PR #41 依 DEC-P306 維持目前基底；Review 完成且準備合併時才 merge 最新 `origin/dev`、重跑 CI、Squash Merge，不 Bypass。
