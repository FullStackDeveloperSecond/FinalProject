## 更改內容

- 新增 `OpenAiResponsesClient`，直接以既有 `HttpClient` 實作 `IAiSupportModelClient`，固定呼叫 OpenAI Responses Endpoint；沒有新增 OpenAI SDK 或可設定的外送 Host。
- Request 固定 `store=false`，不送 `previous_response_id` 或 Tool；User Message 與核准資料以 JSON 信任標籤分離。
- 設定收束為 `OpenAI:ApiKey`、`OpenAI:SupportModel` 與 `OpenAI:SupportTimeoutMilliseconds`；客服預設 Terra、單次 12 秒，功能啟用時缺少或不合法設定即啟動失敗。
- 429、Request Timeout、5xx、網路、截斷或不合法結構最多重試一次；其他 4xx、模型要求人工與呼叫端取消不重試。
- strict Schema 限答案 4,000 字、引用 8 筆；引用只能匹配本次核准來源，標題與版本由後端可信資料覆寫，API 不採用模型 URL。
- 成功回應保留 Provider 實際模型、Input Token 與 Output Token，並傳回 Orchestrator 結果供 M-19 後續保存與成本計算；缺少 Usage 時 Fail Closed。
- Order Context 補上來源型別、PublicId、訂單編號及 `UpdatedAtUtc`，外送內容仍不含姓名、Email、電話、地址或 Owner ID。
- 寫回 DEC-BATCH-033／DEC-P331～P334、AI 規格、Secret 規範、驗收規格、M 矩陣、AI-15 追蹤與評估資料說明。

## 定義與交接契約

| 取用者 | 契約 |
|---|---|
| M-19 客服垂直切片 | 只經 `AiSupportOrchestrator` 呼叫；不得繞過 Admission、Owner Query 或再扣一次額度。使用 `ModelUsage` 保存實際模型與 Token，價格由版本化政策另算 |
| Context Reader | 每筆資料必須提供白名單 SourceType、穩定 SourceId、可信 Title、Version／UpdatedAt 與去識別 Content；非法或重複來源使 Adapter Fail Closed |
| API／前端 | 引用 URL 目前固定 `null`；只有後端可信來源可產生導頁。模型文字不得直接成為 URL 或資源授權依據 |
| 維運 | `Features:AiEnabled=false` 為安全預設；啟用前需設定後端 User Secrets／環境變數，Key 不得進 Git、Log 或 Vue Bundle |
| AI-09 評估 | deterministic tests 不代表真實模型品質；仍須以 120 筆核准資料執行手動 live baseline，保存模型、版本、P95、Token 與成本 |

## 風險與回復

- 已知剩餘風險：尚無真實模型輸出、延遲、Token 分布與成本證據；引用 Grounding 的品質門檻仍待 live evaluation。
- 回復方式：將 `Features:AiEnabled=false` 保持或設回 false，DI 回到既有 Fail Closed 路徑；本批無 Schema／Migration，無資料回復工作。
- 停止條件：發現個資／Secret 外送、越權引用、模型輸出可控制 URL、非暫時錯誤重試或 Usage 無法追蹤時不得合併。
