## 更改內容

- `IAiSupportAdmissionGate` 分成讀取與 `TryReserveAsync`；所有安全與 Owner 檢查通過後、模型呼叫前才預留額度。
- 預留成功後即使模型不可用也不退還；相同互動的 Adapter 內部重試不得再次呼叫預留。
- 新增 `IAiSupportContextReader`；訂單參照必須以登入會員查詢，拒絕映射為 `404 ai_order_access_denied`，尚未接正式 Query 時 Fail Closed。
- `locale` 轉成受控 `SupportedLocale` 並傳入 Prompt Envelope，不再只驗證 DTO 後捨棄。
- `Features:AiEnabled=false` 時 Controller 在任何 Admission／Model 呼叫前回 `503 ai_service_unavailable`。
- Application 只回 `AiSafetyReason`，HTTP Status 與公開錯誤碼集中由 API Controller 映射。
- 原本宣稱 Guest Scope 的測試更正為「錯誤帳號類型」；真正 GuestOrderAccessToken Scheme Integration 明確保留待辦。

## 定義與跨模組取用

| 取用者 | 必須使用的能力 | 規則 |
|---|---|---|
| 同意／額度資料層 | `IAiSupportAdmissionGate` | `TryReserveAsync(memberId, requestPublicId)` 必須具原子性與冪等性；不可先讀後在記憶體減一 |
| 訂單模組 | `IAiSupportContextReader` | 只以可信 Member ID 做 Owner Query，回傳去識別最小內容；不得接受前端 Member ID |
| OpenAI Adapter | `IAiSupportModelClient` | 只接收已通過 Gate 的 Envelope；模型失敗不觸發額度退款或第二次預留 |
| API／前端 | Problem Details | Owner 拒絕使用 `404 ai_order_access_denied`；功能或相依服務不可用使用 `503 ai_service_unavailable` |
