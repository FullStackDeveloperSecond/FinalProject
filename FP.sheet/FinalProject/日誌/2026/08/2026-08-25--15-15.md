## 定義與跨模組取用

| 取用者 | 必須遵守的規則 |
|---|---|
| .NET 開發者 | 套件版本只放 `Directory.Packages.props`；不得在 `.csproj` 放 `Version`／`VersionOverride`；來源只允許 Repository `NuGet.config` 的 nuget.org |
| Vue 開發者 | 直接 Registry 套件使用精確版本並同步 `package-lock.json`；本機共用套件只允許 `@doselect/web-shared=file:../shared` |
| PR 作者 | 沒有新增直接 Package 時填「不適用」；有新增時逐筆提供用途、Registry 與官方來源，不可只貼 Restore 成功 |
| Reviewer／CI 維護者 | `CI Required` 必須包含 `Package Source Evidence`；不可改用未核准 Registry 或移除拒絕路徑測試 |
