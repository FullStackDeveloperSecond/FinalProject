## 定義與組員取用方式

### Health Endpoint

| Endpoint | 現階段定義 | 公開回應 |
|---|---|---|
| `GET /health/live` | API 程序可以處理請求 | `{"status":"Healthy"}` 或對應整體狀態 |
| `GET /health/ready` | `Storage:DataRoot` 可建立目錄及寫入暫存探針 | 只含 `status`；失敗 HTTP 503，不含路徑或例外 |

SQL Server、Migration 與 Hangfire 尚未實作，不得把目前 Ready 解讀為資料庫已就緒。對應 Infrastructure 完成後必須擴充同一 Endpoint。

### 設定契約

- `Storage:DataRoot` 必須是非檔案系統根目錄的絕對路徑；Development 未覆寫時使用系統暫存目錄下的 `DoSelectData`，Demo 設為 `E:\FinalProjectData`。
- `Features:AiEnabled` 與 `Features:EmailEnabled` 預設 `false`。停用時缺 Secret 不阻擋核心 API；明確啟用後，缺少 OpenAI 或 SMTP 必要 Key 會在啟動時失敗。
- `Demo:SimulationEndpointsEnabled=true` 只允許 `Demo` Environment。
- `Observability:FileLoggingEnabled=false` 只停用檔案 Sink，Console JSON 保留。
- 設定驗證訊息只列 Key 名，不得列設定值、帳號、路徑內容或 Secret。

### Logging 契約

- Console 與檔案均為 JSON；檔案路徑 `{Storage:DataRoot}/logs/doselect-api-*.json`。
- 單檔 100 MB、每日切檔、最長保留 14 天且最多 20 檔；診斷工具可共享讀取。
- HTTP 完成事件至少包含 `RequestMethod`、`PathTemplate`、`StatusCode`、`Elapsed`、`CorrelationId`、`TraceId` 與 `UserType`。
- 組員以 `ILogger<T>` 寫入結構化訊息，不直接建立 Serilog 靜態 logger，不記錄 Cookie、Token、API Key、連線字串、完整會員個資或付款資料。
