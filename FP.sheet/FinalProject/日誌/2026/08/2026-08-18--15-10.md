## 更改內容

### 摘要

`global.json` 現在以 `rollForward: disable` 精確要求 `.NET SDK 10.0.302`。其他 Patch、Feature Band 或 Major 即使已安裝也不能替代；SDK 升級須由團隊明確更新基線。

### 新增

- 決策覆寫與追蹤紀錄，說明精確鎖版及本機安裝前置條件。

### 修改

- `FP.dev/global.json`：`latestPatch` 改為 `disable`。
- 開發 README、本機環境基線及系統架構同步精確版本語意。

### 刪除或淘汰

- 淘汰同一 `10.0.3xx` Feature Band 可自動使用較新 Patch 的既有契約。

## 定義與對外契約

### 提供給其他模組的能力或資料

| 能力／資料 | 提供者 | 使用者 | 用途 |
|---|---|---|---|
| `global.json` SDK 契約 | 專案基礎 | 全體開發者、CI | 確保 Restore、Build、Test、Tool 與 User Secrets 使用同一 SDK |

### 正確取用方式

| 項目 | 定義 |
|---|---|
| SDK Version | 精確 `10.0.302` |
| Roll Forward | `disable` |
| Preview | `allowPrerelease: false` |
| 成功條件 | 在 `FP.dev` 執行 `dotnet --version` 必須輸出 `10.0.302` |

### 必須維持的規則

- 全組與 CI 使用精確 `.NET SDK 10.0.302`。
- 不以 `10.0.303`、`10.0.400` 或其他版本替代。
- SDK 可並存；不得為符合本專案而刪除其他專案需要的 SDK。
- 升級 SDK 必須獨立決策並重新執行 Restore、Build、Format 與 Test。

### 禁止或不建議的取用方式

- 不得在個人電腦修改 Repository 的 `global.json` 規避安裝。
- 不得把 SMTP Key、API Key 或其他 Secret 寫入版本檔或日誌。

## 相容性、風險與注意事項

- 相容性影響：其他尚未安裝 `10.0.302` 的電腦會立即無法執行本專案任何 .NET CLI 指令，這是精確鎖版的預期行為；本展示電腦已完成安裝與驗證。
- 已知風險：版本升級不再自動取得 Patch 修正，團隊需主動評估並整批升級。
- 回復方式：只有新的團隊決策才可修改 `global.json`；不以個人暫時改檔規避。
- 需要其他負責人配合：五位成員皆須執行 `dotnet --version` 並確認 `10.0.302`。
