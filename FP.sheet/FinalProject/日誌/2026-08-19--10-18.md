## 更改內容

- 以 Windows Authentication 將 `20260819013357_InitialCreate` 套用至 `.\SQL2025` 的 `DoSelectDb`。
- 新增 `verify.sql`，驗證 93 張應用／Identity 表、315 個索引、`vw_CaseWorkbench` 12 欄及 Migration History。
- Identity DI 加入 `ApplicationUser`、十個正式角色與 EF Core Store；API 一般啟動不自動 Migrate 或 Seed。
- 新增明確 `--seed-minimal` 流程，建立兩個已確認 Email 的開發帳號、兩個 Profile 與一組虛構型錄。
- 管理員只先指派 SuperAdmin；Seed 不預先綁定 TOTP，重跑也不會關閉後續已設定的 TOTP。
- Seed 密碼只從 `Seed:AdminPassword`／`Seed:MemberPassword` User Secrets 取得；互動腳本先檢查 Identity 預設密碼規則。
- 新增 `verify-minimal-seed.sql`；第二次 Seed 執行角色、帳號、Profile、型錄新增數均為 0。
- `/health/ready` 新增 EF Core `SELECT 1` 實際讀取；公開回應維持只有整體 `status`。
- 新增 `smoke-api-database.ps1`，以固定 SDK／Port 暫時啟動 API、驗證 Ready 後安全停止受管程序。
- EF Core 框架日誌最低層級調為 Warning，避免開發環境輸出大量查詢計畫與參數結構。

## 定義與對外契約

| 項目 | 定義 |
|---|---|
| Migration | 必須明確執行 `database update InitialCreate`；API 不自動更新 Schema |
| Seed | 必須明確執行 `scripts/seed-minimal-development-data.ps1`；一般啟動不自動 Seed |
| Seed 帳號 | `admin@doselect.local`、`member@doselect.local`；密碼不進版控 |
| 角色 | SuperAdmin 等十個正式角色；初始管理員只指派 SuperAdmin |
| Seed 冪等 | 以角色名、Email、型錄 Code 尋找；既有帳號不重設密碼 |
| SQL Ready | EF Core 執行 `SELECT CAST(1 AS int) AS [Value]`；失敗回 503 且公開 Body 不含依賴細節 |
| 範圍邊界 | 最小 Seed 只供組員開發，不取代 DATA-06 的 10,000 筆展示資料 |
